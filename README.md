# Карта Знаний

## Запуск для разработки

### Фронтенд

```bash
cd client/
bun dev
```

### Бэкенд

- Запустите Docker Desktop
- Запустите файл `.\start_local_dev.ps1`

## Сервисы

1. `ai` — обеспечивает доступ системы к AI
2. `api` — шлюз через который все другие сервисы общаются с клиентом
3. `auth` — аутентификация пользователей
4. `client` — веб-клиент
5. `data_to_db` — сохранение данных из различных внешних источников в базу данных и хранилище
6. `knowledge_map_core` — ядро системы, основные структуры и алгоритмы
7. `laying` — укладка DAG карты знаний
8. `nlp` — обработка естественных языков
9. `pdf_to_md` — преобразование PDF в Markdown
10. `xml_to_md` — преобразование XML в Markdown

## Архитектура

Микросервисная функциональная архитектура  
  
- Ядро Карты Знаний
  - Постановка цели
  - Генерация нового знания к конкретной цели
  - Обратное планирование от цели. Декомпозиция
  - Получение вложенности одного в другое
  - Обнаружение опровержений
  - Обнаружение противоречий
  - Разрешение противоречий
- Укладка графа
- NLP
  - Получение сущностей из текстов (NER)
  - Получение цепочек действий из текстов
  - Получение зависимостей паттернов действий друг от друга
  - Получение зависимостей успешных паттернов действий друг от друга
- Клиенты
  - Браузерный
  - Программный
    - Python
- Хранилище
  - S3
- Базы данных
  - Neo4j
- Загрузчики данных
  - PubMed baseline
  - PubMed Central
- Исследования
  - Успешные паттерны зависимости действий друг от друг
  - Обнаружение "Таблицы Менделеева" для знаний. Атомарных единиц знаний вроде грамем
  - Уникальность знания
  - Предсказательная сила Карты Знаний
