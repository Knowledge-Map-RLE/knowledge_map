Анализ твоего подхода
Твоя логика:

Предшественники A (P → A) должны также → B'
Последователи B (B → S) должны от A' → S
Проблема: Если оставить старые связи + новые, получится P → A → B и P → B' плюс A' → S и B → S. Это может создать новые циклы.

Уточнение: Лучше заменять, а не добавлять:

Вместо P → A делаем P → B'
Вместо B → S делаем A' → S
Это сохраняет "поток" через копии, но старый путь через A → B удаляется.

Альтернативные варианты
Вариант 2: Сохранить только обратную связь

При цикле A ← B (B → A) просто инвертировать направление
Проблема: теряется семантика (причина → следствие)

# Итог по пороблеме выявления действий из текста

Хорошие вопросы. Давайте разберём:

## Проблема 1: Выявление ролей

Текущий ActionExtractor уже делает это через **DEP + lemma**:

```
"Rapamycin inhibits mTOR"
     nsubj     VERB   dobj
```

**Правило:**
```
Если dep = nsubj AND lemma ∈ {inhibit, block, suppress}:
    → role = "inhibitor"
Если dep = dobj AND lemma ∈ {inhibit, block, suppress}:
    → role = "inhibited_entity"
```

Это **уже задано** в алгоритмах (action_extractor.py:283-353).

---

## Проблема 2: Маркеры ненадёжны

**Решение: не использовать маркеры для причинности.**

Вместо маркеров — **Graph alignment:**

```
A: inhibit(X) → activate(X) → extend(X,Y)
B: inhibit(X') → activate(X') → extend(X',Y')
```

Причинность **implícita** в структуре подграфа — не нужен маркер "causes".

---

## Как алгоритм справится:

**Шаг 1: NLP извлекает структуру**
```
sentence → DEPENDS_ON граф (syntactic)
```

**Шаг 2: Pattern matching на уровне структуры**
```
"inhibit(Rapamycin, mTOR)" — это inhibit с 2 аргументами
"inhibit(Metformin, AMPK)" — это inhibit с 2 аргументами
```
Результат: общий паттерн `inhibit(X, Y)`

**Шаг 3: Извлечение ролей из структуры**
```
nsubj(X) → VERB{inhibit} → dobj(Y)
              ↓
role(X) = "inhibitor"
role(Y) = "inhibited"
```

**Шаг 4: Причинность через alignment**
```
X → inhibit → Y (одно предложение)
X → activate → Y (другое предложение)

Если object(inhibit) == subject(activate):
    → edge inhibit → activate (без маркера!)
```

---

## Итого rule-based:

| Аспект | Решение |
|--------|--------|
| Роли | DEP + lemma dictionary |
| Причинность | Graph alignment (не маркеры) |
| Структура | DEPENDS_ON граф |

---

# Покажи, какой минимальный стек логик лучше всего подходит именно для моего проекта

Хорошо, давай без абстракций — соберём **минимальный, но реально рабочий стек логик** именно под твою задачу:
(научные статьи → причинно-следственные цепочки → DAG → обратное планирование).

Сразу главное: тебе не нужна “одна суперлогика”. Тебе нужен **слоёный стек**, где каждый слой решает *свою* задачу и не взрывается по сложности.

---

## 🧠 Минимальный стек логик для “Карты Знаний”

### 1. База: факты и структура → First-Order Logic (FOL)

Это твой фундамент. Без него никуда.

Что хранить:

* сущности (drug, protein, method)
* отношения (causes, inhibits, increases)
* события

Пример:

```
Inhibits(DrugA, ProteinB)
Causes(ProteinB, DiseaseC)
```

👉 Это идеально ложится в Neo4j:

```
(:DrugA)-[:INHIBITS]->(:ProteinB)-[:CAUSES]->(:DiseaseC)
```

✔ Почему FOL:

* достаточно выразительна для научных фактов
* хорошо индексируется
* можно делать быстрые запросы

❗ Но:

* **не умеет** работать с неопределённостью
* **не умеет** описывать время и процессы нормально

---

### 2. Правила и вывод → Datalog (ограниченная FOL)

Это ключевой слой, который тебе сейчас не хватает.

Ты хочешь:

> находить цепочки действий → успешные / тупиковые

Это **не факты**, это **выводимые паттерны**.

Пример:

```
Success(X, Z) :- Causes(X, Y), Causes(Y, Z), Positive(Z)
```

✔ Почему Datalog:

* гарантированно полиномиальный
* нет комбинаторного взрыва как в полном FOL
* идеально для DAG

👉 Это твой основной engine для:

* поиска цепочек
* агрегации паттернов
* обратного планирования

---

### 3. Неопределённость → Probabilistic Logic

Научные статьи ≠ истина. Там:

* “likely”
* “suggests”
* “may cause”

Если ты это игнорируешь — ты теряешь половину смысла.

Пример:

```
Causes(DrugA, EffectB) [0.7]
```

✔ Что использовать:

* ProbLog
* или просто веса на рёбрах в графе

👉 В графе:

```
(:A)-[:CAUSES {p:0.7}]->(:B)
```

✔ Это позволяет:

* находить **наиболее вероятные цепочки**
* а не просто любые

---

### 4. Время и процесс → Temporal Logic (минимально)

Тебе не нужна full LTL/CTL.
Но нужно понимать порядок:

```
Step1 → Step2 → Step3
```

Пример:

```
Before(Treatment, Recovery)
```

или в графе:

```
(:Step1)-[:BEFORE]->(:Step2)
```

✔ Нужно для:

* последовательностей действий
* сценариев (workflow)
* обратного планирования

---

### 5. Ограничения / тупики → Constraint Logic

Это очень важно для твоей идеи:

> “цепочки, которые заводят в тупик”

Пример:

```
DeadEnd(X) :- Causes(X, Y), Negative(Y)
```

или:

```
INVALID_PATH if leads_to contradiction
```

✔ Это:

* фильтр графа
* pruning (срезание веток)

---

## 🔥 Как это всё соединяется (самое важное)

Вот твоя реальная архитектура:

```
                [ NLP ]
                  ↓
        ┌──────────────────┐
        │  FOL (граф)      │  ← Neo4j
        │  факты           │
        └──────────────────┘
                  ↓
        ┌──────────────────┐
        │ Datalog rules    │  ← вывод цепочек
        └──────────────────┘
                  ↓
        ┌──────────────────┐
        │ Probabilities    │  ← веса
        └──────────────────┘
                  ↓
        ┌──────────────────┐
        │ Constraints      │  ← тупики
        └──────────────────┘
                  ↓
        ┌──────────────────┐
        │ Backward planner │
        └──────────────────┘
```

---

## 🚀 Как это решает твою проблему

### ❌ Было:

* поиск подграфов
* NP / экспонента
* комбинаторный взрыв

### ✅ Стало:

* вывод через правила (Datalog)
* ограниченное пространство поиска
* pruning через constraints
* вероятностная оптимизация

👉 Это уже **не subgraph isomorphism**, а:

> controlled reasoning over graph

---

## 🧩 Как выглядит обратное планирование

Цель:

```
Goal: CureDisease
```

Ты ищешь:

```
?X → CureDisease
```

Через правила:

```
CureDisease :- Inhibits(X, ProteinY), Causes(ProteinY, Disease)
```

→ находишь кандидатов
→ строишь цепочки назад
→ фильтруешь через constraints
→ ранжируешь по вероятности

---

## ⚠️ Почему это минимальный стек

Я специально НЕ добавил:

* higher-order logic → слишком тяжело
* full modal logic → избыточно
* dependent types → не нужно

---

## 💡 Ключевая мысль

Ты строишь не “граф знаний”.

Ты строишь:

> **систему вывода над графом с ограничениями и вероятностями**

Да. В итоге тебе нужен не “один текстовый формат”, а **каноническое вычисляемое представление знаний** в виде:

**typed proposition DAG + provenance + modality/confidence + rule layer**.

То есть результат преобразования статьи — это не абзацы и не просто граф слов, а набор атомарных утверждений вида:

```text
predicate(entity_a, entity_b)
```

с метаданными:

```text
source_span, doc_id, sentence_id, modality, confidence, derived_from
```

а поверх этого — правила Datalog для вывода новых фактов. Для биомедицинского текста это удобно строить на `en_core_sci_scibert`: scispaCy прямо даёт full pipeline для biomedical text, а `en_core_sci_scibert` использует большой словарь и `allenai/scibert-base` как transformer model. spaCy же рекомендует `nlp.pipe(...)` для потоковой обработки и отключение ненужных компонентов ради скорости; для правил доступны `EntityRuler` и `DependencyMatcher`. ([allenai.github.io][1])

# knowledge_compiler.py
from __future__ import annotations

from dataclasses import dataclass, field, asdict
from pathlib import Path
from typing import Dict, List, Tuple, Iterable, Optional
import csv
import hashlib
import json
import re

import spacy
from spacy.language import Language
from spacy.matcher import DependencyMatcher
from spacy.pipeline import EntityRuler
import networkx as nx


# -----------------------------
# Canonical data structures
# -----------------------------

@dataclass(frozen=True)
class SpanRef:
    doc_id: str
    sent_id: int
    start_char: int
    end_char: int
    text: str


@dataclass(frozen=True)
class Proposition:
    """
    Canonical computable knowledge unit.
    Example:
        influenced_by(pd, genetic_factor)
        characterized_by(ipd, bradykinesia)
    """
    predicate: str
    args: Tuple[str, ...]
    polarity: str = "positive"          # positive | negated
    modality: str = "asserted"          # asserted | probable | speculative | recommended
    confidence: float = 1.0
    provenance: Tuple[SpanRef, ...] = field(default_factory=tuple)

    def key(self) -> str:
        raw = f"{self.predicate}({','.join(self.args)})|{self.polarity}|{self.modality}"
        return hashlib.sha1(raw.encode("utf-8")).hexdigest()[:16]


@dataclass(frozen=True)
class Entity:
    canonical: str
    label: str
    aliases: Tuple[str, ...] = ()


# -----------------------------
# DAG knowledge graph builder
# -----------------------------

class KnowledgeDAG:
    def __init__(self) -> None:
        self.g = nx.DiGraph()

    def add_entity_node(self, ent: Entity) -> str:
        node_id = f"ent::{ent.canonical}"
        if node_id not in self.g:
            self.g.add_node(
                node_id,
                kind="entity",
                canonical=ent.canonical,
                label=ent.label,
                aliases=list(ent.aliases),
            )
        return node_id

    def add_prop_node(self, prop: Proposition) -> str:
        node_id = f"prop::{prop.key()}"
        if node_id not in self.g:
            self.g.add_node(
                node_id,
                kind="proposition",
                predicate=prop.predicate,
                args=list(prop.args),
                polarity=prop.polarity,
                modality=prop.modality,
                confidence=prop.confidence,
                provenance=[asdict(p) for p in prop.provenance],
                canonical=f"{prop.predicate}({', '.join(prop.args)})",
            )
        return node_id

    def support(self, prop: Proposition) -> str:
        return self.add_prop_node(prop)

    def derive(self, derived: Proposition, premises: Iterable[Proposition], rule_name: str) -> str:
        d_id = self.add_prop_node(derived)
        for prem in premises:
            p_id = self.add_prop_node(prem)
            self.g.add_edge(p_id, d_id, kind="DERIVED_FROM", rule=rule_name)
        return d_id

    def add_support_edge(self, prop: Proposition, evidence_label: str = "SUPPORTED_BY") -> None:
        p_id = self.add_prop_node(prop)
        for prov in prop.provenance:
            e_id = f"ev::{hashlib.sha1((prov.doc_id + str(prov.sent_id) + prov.text).encode()).hexdigest()[:16]}"
            if e_id not in self.g:
                self.g.add_node(
                    e_id,
                    kind="evidence",
                    doc_id=prov.doc_id,
                    sent_id=prov.sent_id,
                    start_char=prov.start_char,
                    end_char=prov.end_char,
                    text=prov.text,
                )
            self.g.add_edge(e_id, p_id, kind=evidence_label)

    def topological_propositions(self) -> List[str]:
        # Works because we only add directed evidence->fact and fact->derived edges.
        return list(nx.topological_sort(self.g))

# Text -> canonical facts compiler
# -----------------------------

class TextToKnowledgeCompiler:
    def __init__(self, model_name: str = "en_core_sci_scibert") -> None:
        self.nlp = spacy.load(model_name)

        # Rule-based entity layer for stable domain terms / aliases.
        ruler = self._ensure_entity_ruler()
        ruler.add_patterns([

    def compile(self, text: str, doc_id: str) -> KnowledgeDAG:
        # Use batching if compiling lots of texts; here a single doc is fine.
        docs = list(self.nlp.pipe([text], batch_size=1))
        doc = docs[0]

        # Sentence index for provenance
        sent_map = {sent.start: i for i, sent in enumerate(doc.sents)}
        sents = list(doc.sents)

        for sent_id, sent in enumerate(sents):
            prov = SpanRef(
                doc_id=doc_id,
                sent_id=sent_id,
                start_char=sent.start_char,
                end_char=sent.end_char,
                text=sent.text,
            )

            # 1) Direct entity facts
            ents = self._extract_entities(sent.text)
            for ent in ents:
                self.graph.add_entity_node(ent)

            # 2) Pattern extraction
            props = self._extract_propositions_from_sentence(doc, sent, prov)

            # 3) Add proposition nodes + provenance
            for p in props:
                self.graph.add_support_edge(p)

            # 4) Optional rule-based derived facts (tiny example)
            for p in props:
                self._apply_local_rules(p, prov)

        return self.graph

    def _extract_entities(self, sentence: str) -> List[Entity]:
        # Deterministic canonicalization layer.
        lowered = sentence.lower()
        found: List[Entity] = []
        for surface, ent in self.known_entities.items():
            if surface.lower() in lowered:
                found.append(ent)
        return found

    def _extract_propositions_from_sentence(
        self,
        doc,
        sent,
        prov: SpanRef,
    ) -> List[Proposition]:
        props: List[Proposition] = []

        # Rule 1: simple lexical patterns for the sample article.
        text = sent.text.lower()

        if "age-related" in text:
            props.append(Proposition("age_related", ("pd",), provenance=(prov,)))
        if "multifactorial" in text:
            props.append(Proposition("multifactorial", ("pd",), provenance=(prov,)))
        if "genetic" in text:
            props.append(Proposition("influenced_by", ("pd", "genetic_factor"), provenance=(prov,)))
        if "environmental" in text:
            props.append(Proposition("influenced_by", ("pd", "environmental_factor"), provenance=(prov,)))
        if "bradykinesia" in text and "necessary condition" in text:
            props.append(Proposition("necessary_condition_for", ("bradykinesia", "ipd"), provenance=(prov,)))
        if "main feature" in text and "bradykinesia" in text:
            props.append(Proposition("main_feature_of", ("bradykinesia", "ipd"), provenance=(prov,)))
        if "characterized by" in text:
            # Extract rough subject and symptom mentions
            if "bradykinesia" in text:
                props.append(Proposition("characterized_by", ("ipd", "bradykinesia"), provenance=(prov,)))
            if "resting tremor" in text:
                props.append(Proposition("characterized_by", ("ipd", "resting_tremor"), provenance=(prov,)))
            if "rigidity" in text:
                props.append(Proposition("characterized_by", ("ipd", "rigidity"), provenance=(prov,)))
            if "postural instability" in text:
                props.append(Proposition("characterized_by", ("ipd", "postural_instability"), provenance=(prov,)))
        if "can precede" in text or "often start prior to" in text or "prior to the onset" in text:
            if "hyposmia" in text:
                props.append(Proposition("can_precede", ("hyposmia", "core_motor_syndrome"), modality="probable", provenance=(prov,)))
            if "sleep behavior disorder" in text or "sleep disturbances" in text:
                props.append(Proposition("can_precede", ("sleep_disturbance", "core_motor_syndrome"), modality="probable", provenance=(prov,)))

        # 2) Dependency matcher (better coverage for other texts)
        matches = self.dep_matcher(doc[sent.start : sent.end])
        for match_id, token_ids in matches:
            name = self.nlp.vocab.strings[match_id]
            span = doc[sent.start + min(token_ids): sent.start + max(token_ids) + 1]
            # In a real system, replace this with robust argument resolution.
            if name == "COPULAR":
                subj = self._find_lemma_in_span(span, {"pd", "ipd", "parkinson's disease"}) or "unknown_subject"
                attr = self._find_head_like_lemma(span) or "unknown_attr"
                props.append(Proposition("is_a", (subj, attr), provenance=(prov,)))
            elif name == "CHAR_BY":
                subj = self._find_lemma_in_span(span, {"pd", "ipd"}) or "unknown_subject"
                props.append(Proposition("characterized_by", (subj, "unknown_characteristic"), provenance=(prov,)))
            elif name == "INFLUENCED_BY":
                subj = self._find_lemma_in_span(span, {"pd", "ipd"}) or "unknown_subject"
                props.append(Proposition("influenced_by", (subj, "unknown_factor"), provenance=(prov,)))

        return self._dedupe_props(props)

    def _apply_local_rules(self, prop: Proposition, prov: SpanRef) -> None:
        # Example rule layer: derive higher-level claims.
        if prop.predicate == "multifactorial" and prop.args == ("pd",):
            # derived claim
            derived = Proposition("complex_disease", ("pd",), modality="asserted", confidence=0.95, provenance=(prov,))
            self.graph.derive(derived, [prop], rule_name="R_complex_disease")
        if prop.predicate == "age_related" and prop.args == ("pd",):
            derived = Proposition("age_related_complexity", ("pd",), modality="asserted", confidence=0.90, provenance=(prov,))
            self.graph.derive(derived, [prop], rule_name="R_age_related_complexity")
        if prop.predicate == "main_feature_of" and prop.args == ("bradykinesia", "ipd"):
            derived = Proposition("diagnostic_hallmark", ("bradykinesia", "ipd"), modality="asserted", confidence=0.93, provenance=(prov,))
            self.graph.derive(derived, [prop], rule_name="R_diagnostic_hallmark")

    @staticmethod
    def _dedupe_props(props: List[Proposition]) -> List[Proposition]:
        seen = set()
        out = []
        for p in props:
            k = (p.predicate, p.args, p.polarity, p.modality)
            if k not in seen:
                seen.add(k)
                out.append(p)
        return out

    @staticmethod
    def _find_lemma_in_span(span, candidates: set[str]) -> Optional[str]:
        for tok in span:
            if tok.lemma_.lower() in candidates or tok.text.lower() in candidates:
                return tok.lemma_.lower()
        return None

    @staticmethod
    def _find_head_like_lemma(span) -> Optional[str]:
        # Very small heuristic: return nominal head lemma if present
        heads = [t for t in span if t.pos_ in {"NOUN", "PROPN", "ADJ"}]
        if heads:
            return heads[-1].lemma_.lower()
        return None

    def export_souffle_csv(self, graph: KnowledgeDAG, out_dir: str) -> None:
        """
        Export canonical facts for a Soufflé input relation.
        You can later use Soufflé's Python SWIG wrapper or C++ interface
        to load CSV facts and run Datalog rules. The official Soufflé docs
        describe both the SWIG Python interface and the generated C++ interface. :contentReference[oaicite:1]{index=1}
        """
        out = Path(out_dir)
        out.mkdir(parents=True, exist_ok=True)

        facts_path = out / "fact.facts"
        with facts_path.open("w", newline="", encoding="utf-8") as f:
            writer = csv.writer(f)
            # relation: fact(predicate, arg1, arg2, doc_id, sent_id, modality, confidence)
            for n, data in graph.g.nodes(data=True):
                if data.get("kind") != "proposition":
                    continue
                args = data.get("args", [])
                pred = data.get("predicate", "")
                doc_id = ""
                sent_id = -1
                modality = data.get("modality", "asserted")
                confidence = data.get("confidence", 1.0)

                prov = data.get("provenance", [])
                if prov:
                    doc_id = prov[0]["doc_id"]
                    sent_id = prov[0]["sent_id"]

                arg1 = args[0] if len(args) > 0 else ""
                arg2 = args[1] if len(args) > 1 else ""
                writer.writerow([pred, arg1, arg2, doc_id, sent_id, modality, confidence])

        # Optional: emit a starter rules file.
        rules_path = out / "rules.dl"
        rules_path.write_text(
            """

.input fact

.decl complex_disease(x:symbol)
complex_disease(x) :- fact("multifactorial", x, _, _, _, _, _).
complex_disease(x) :- fact("age_related", x, _, _, _, _, _).

.decl diagnostic_hallmark(sym:symbol, d:symbol)
diagnostic_hallmark(sym, d) :- fact("main_feature_of", sym, d, _, _, _, _), fact("necessary_condition_for", sym, d, _, _, _, _).
""".strip(),
            encoding="utf-8",
        )

Если под каждый новый текст писать новые правила, то получится не символический интеллект, а набор ручных шаблонов. Это слабое место.

Но это **не значит, что символический подход плох**. Это значит, что нужен не “правило на предложение”, а **универсальный слой извлечения + отдельный слой смысла + отдельный слой вывода**.

## В чём должна быть разница

Слабый вариант:

* для PD пишем одни правила,
* для онкологии — другие,
* для химии — третьи,
* для нового текста — ещё пачку.

Сильный вариант:

* есть **ограниченный набор универсальных шаблонов смысла**,
* есть **онтология**,
* есть **словарь синонимов и алиасов**,
* есть **композиция правил**,
* есть **индукция новых правил из корпуса**.

То есть меняется не код под текст, а **сопоставление текста с уже существующей системой смыслов**.

---

## Как сделать систему гибкой

### 1) Не правила под текст, а правила под тип конструкции

Например, не:

* “в этой статье `symptomatic_treatment_of`”
* “в другой статье `associated_with`”
* “в третьей `can_precede`”

А универсальные паттерны:

* `X is Y`
* `X is characterized by Y`
* `X is associated with Y`
* `X may precede Y`
* `X inhibits Y`
* `X treats Y`
* `X causes Y`

Это уже не под конкретный текст, а под **структуру научного языка**.

---

### 2) Смысл хранится в онтологии, а не в имени роли

Вместо длинных и хрупких имён вроде:

```prolog
symptomatic_treatment_of(X, Y)
```

лучше иметь базовые атомы:

```prolog
treats(X, Y)
has_mode(X, symptomatic)
```

А `symptomatic_treatment_of` — это уже **выводимое понятие**:

```prolog
symptomatic_treatment_of(X, Y) :-
    treats(X, Y),
    has_mode(X, symptomatic).
```

Тогда новый текст не требует новой логики, если он выражает ту же комбинацию смыслов другими словами.

---

### 3) Нужен слой канонизации, а не ручной разметки

Текст может говорить:

* “relates to”
* “associated with”
* “linked to”
* “connected with”

Но для системы это может сводиться к одному канону:

```prolog
related_to(X, Y)
```

Иначе да, всё развалится.

То есть ключ — **не правила на слова, а нормализация разных форм к одному смысловому ядру**.

---

### 4) Нужны шаблоны по синтаксису и семантическим ролям

Тут как раз и полезны spaCy / dependency parse / entity linking.

Не правило “если в предложении есть слово Parkinson’s disease…”, а правило вида:

* найти субъект,
* найти связку,
* найти предикатив,
* найти модификаторы,
* найти отрицание,
* найти модальность.

Это уже устойчиво к разным текстам.

---

### 5) Символьный интеллект должен уметь **обобщать**

Самая важная часть:
символьная система не должна хранить только отдельные факты. Она должна строить:

* классы,
* подтипы,
* композиции,
* правила наследования,
* ограничения,
* аналогии.

Например:

```prolog
if X is a symptom and X can precede core_motor_syndrome
then X is prodromal.
```

Это работает не только для hyposmia, а для любого симптома, который попадает под те же условия.

---

## Почему мой прошлый пример был полезен, но не финальный

Он был **скелетом компилятора смысла**, а не законченной системой.

Чтобы система стала гибкой, нужно заменить “ручные if по строкам” на такой pipeline:

1. **parser** — извлекает синтаксическую структуру,
2. **mapper** — переводит структуру в канонические предикаты,
3. **normalizer** — сводит синонимы к одному канону,
4. **ontology linker** — привязывает термины к типам,
5. **rule engine** — делает вывод,
6. **rule induction** — предлагает новые правила из корпуса,
7. **human review** — подтверждает новые обобщения.

---

## Как не потерять силу символического подхода

Сила символики не в том, что она “всё знает заранее”.
Сила в том, что она:

* явно хранит смысл,
* композиционна,
* проверяема,
* объяснима,
* переиспользуема.

Чтобы это работало на новых текстах, нужно сделать **малое число очень общих, но хорошо сконструированных правил**, а не много частных.

---

## Что должно меняться при новом тексте

Не правила.
Должны меняться:

* алиасы сущностей,
* словарь терминов,
* маппинг лексических конструкций,
* веса уверенности,
* новые производные правила, если корпус показывает устойчивость.

То есть новый текст расширяет систему **данными и канонизацией**, а не переписыванием логики.

---

## Правильная формулировка для твоего проекта

Тебе нужен не “ручной извлекатель Datalog-фактов”, а:

> **универсальный символический компилятор естественного языка в канонические предикаты, работающий через онтологию, шаблоны конструкций, нормализацию и вывод**

from __future__ import annotations

from dataclasses import dataclass, field, asdict
from pathlib import Path

# 1) Canonical layer

def slugify(text: str) -> str:
    text = text.strip().lower()
    text = re.sub(r"[^\w\s-]", "", text)
    text = re.sub(r"[\s-]+", "_", text)
    return text.strip("_") or "unknown"


@dataclass(frozen=True)
class SpanRef:
    doc_id: str
    sent_id: int
    start_char: int
    end_char: int
    text: str


@dataclass(frozen=True)
class Mention:
    canonical_id: str
    label: str
    surface: str
    start_char: int
    end_char: int


@dataclass(frozen=True)
class Fact:
    """
    Canonical computable proposition.
    Examples:
      influenced_by(pd, genetic_factor)
      characterized_by(ipd, bradykinesia)
      is_a(bradykinesia, symptom)
    """
    predicate: str
    args: Tuple[str, ...]
    polarity: str = "positive"      # positive | negated
    modality: str = "asserted"      # asserted | probable | speculative | recommended
    confidence: float = 1.0
    provenance: Tuple[SpanRef, ...] = field(default_factory=tuple)
    source: str = "direct"         # direct | derived

    def key(self) -> str:
        raw = f"{self.predicate}({','.join(self.args)})|{self.polarity}|{self.modality}|{self.source}"
        return hashlib.sha1(raw.encode("utf-8")).hexdigest()[:16]


@dataclass(frozen=True)
class OntologyEntity:
    canonical: str
    label: str
    aliases: Tuple[str, ...] = ()


@dataclass(frozen=True)
class OntologyRelation:
    canonical: str
    aliases: Tuple[str, ...] = ()


@dataclass
class CompilerResult:
    doc_id: str
    text: str
    facts: List[Fact]
    mentions: List[Mention]
    graph: nx.DiGraph

class OntologyStore:
    """
    Optional JSON-backed ontology registry.

    Example config:
    {
      "entities": [
        {"canonical": "pd", "label": "DISEASE", "aliases": ["Parkinson's disease", "PD"]},
        {"canonical": "ipd", "label": "DISEASE", "aliases": ["Idiopathic Parkinson's disease", "IPD"]}
      ],
      "relations": [
        {"canonical": "associated_with", "aliases": ["associated with", "linked to"]},
        {"canonical": "characterized_by", "aliases": ["characterized by"]},
        {"canonical": "influenced_by", "aliases": ["influenced by", "affected by"]},
        {"canonical": "precedes", "aliases": ["precedes", "prior to"]},
        {"canonical": "causes", "aliases": ["causes", "leads to", "results in"]},
        {"canonical": "treats", "aliases": ["treats", "treated by"]},
        {"canonical": "requires", "aliases": ["requires", "needs"]}
      ]
    }
    """

    def __init__(self, config_path: Optional[str] = None):
        self.entities: Dict[str, OntologyEntity] = {}
        self.entity_alias_to_canonical: Dict[str, str] = {}
        self.relations: Dict[str, OntologyRelation] = {}
        self.relation_alias_to_canonical: Dict[str, str] = {}

        self._load_defaults()
        if config_path:
            self.load_json(config_path)

    def _load_defaults(self) -> None:
        # Generic scientific vocabulary, not article-specific.
        default_entities = [
            OntologyEntity("disease", "TYPE", ("disease", "diseases")),
            OntologyEntity("symptom", "TYPE", ("symptom", "symptoms")),
            OntologyEntity("factor", "TYPE", ("factor", "factors")),
            OntologyEntity("mechanism", "TYPE", ("mechanism", "mechanisms")),
            OntologyEntity("treatment", "TYPE", ("treatment", "treatments", "therapy", "therapies")),
            OntologyEntity("process", "TYPE", ("process", "processes")),
            OntologyEntity("outcome", "TYPE", ("outcome", "outcomes")),
            OntologyEntity("method", "TYPE", ("method", "methods")),
            OntologyEntity("population", "TYPE", ("population", "populations")),
            OntologyEntity("result", "TYPE", ("result", "results")),
        ]
        default_relations = [
            OntologyRelation("is_a", ("is a", "are", "was", "were", "be")),
            OntologyRelation("has_property", ("has property", "is", "are")),
            OntologyRelation("associated_with", ("associated with", "linked to", "related to", "correlated with")),
            OntologyRelation("characterized_by", ("characterized by", "defined by")),
            OntologyRelation("influenced_by", ("influenced by", "affected by", "shaped by")),
            OntologyRelation("precedes", ("precedes", "prior to", "before")),
            OntologyRelation("causes", ("causes", "leads to", "results in", "produces", "induces")),
            OntologyRelation("treats", ("treats", "treated by", "therapy for")),
            OntologyRelation("requires", ("requires", "needs", "depends on")),
            OntologyRelation("supports", ("supports", "suggests", "indicates", "implies")),
            OntologyRelation("organizes", ("organizes", "organised around", "organized around")),
            OntologyRelation("involves", ("involves", "includes", "contains")),
        ]

        for ent in default_entities:
            self.add_entity(ent)
        for rel in default_relations:
            self.add_relation(rel)

    def load_json(self, path: str) -> None:
        data = json.loads(Path(path).read_text(encoding="utf-8"))

        for item in data.get("entities", []):
            self.add_entity(
                OntologyEntity(
                    canonical=item["canonical"],
                    label=item.get("label", "UNKNOWN"),
                    aliases=tuple(item.get("aliases", [])),
                )
            )
        for item in data.get("relations", []):
            self.add_relation(
                OntologyRelation(
                    canonical=item["canonical"],
                    aliases=tuple(item.get("aliases", [])),
                )
            )

    def add_entity(self, ent: OntologyEntity) -> None:
        self.entities[ent.canonical] = ent
        self.entity_alias_to_canonical[ent.canonical.lower()] = ent.canonical
        self.entity_alias_to_canonical[ent.label.lower()] = ent.canonical
        for alias in ent.aliases:
            self.entity_alias_to_canonical[alias.lower()] = ent.canonical

    def add_relation(self, rel: OntologyRelation) -> None:
        self.relations[rel.canonical] = rel
        self.relation_alias_to_canonical[rel.canonical.lower()] = rel.canonical
        for alias in rel.aliases:
            self.relation_alias_to_canonical[alias.lower()] = rel.canonical

    def canonicalize_entity(self, text: str, label: Optional[str] = None) -> str:
        key = text.strip().lower()
        if key in self.entity_alias_to_canonical:
            return self.entity_alias_to_canonical[key]
        if label:
            lbl = label.strip().lower()
            if lbl in self.entity_alias_to_canonical:
                return self.entity_alias_to_canonical[lbl]
        return slugify(text)

    def canonicalize_relation(self, text: str) -> str:
        key = text.strip().lower()
        if key in self.relation_alias_to_canonical:
            return self.relation_alias_to_canonical[key]
        return slugify(text)

    def entity_label(self, canonical: str) -> str:
        return self.entities.get(canonical, OntologyEntity(canonical, "UNKNOWN")).label

class KnowledgeDAG:
    """
    DAG where:
      evidence/span nodes -> fact nodes -> derived fact nodes
    """
    def __init__(self) -> None:
        self.g = nx.DiGraph()

    def add_span_node(self, prov: SpanRef) -> str:
        node_id = f"span::{hashlib.sha1((prov.doc_id + str(prov.sent_id) + prov.text).encode()).hexdigest()[:16]}"
        if node_id not in self.g:
            self.g.add_node(
                node_id,
                kind="span",
                doc_id=prov.doc_id,
                sent_id=prov.sent_id,
                start_char=prov.start_char,
                end_char=prov.end_char,
                text=prov.text,
            )
        return node_id

    def add_fact_node(self, fact: Fact) -> str:
        node_id = f"fact::{fact.key()}"
        if node_id not in self.g:
            self.g.add_node(
                node_id,
                kind="fact",
                predicate=fact.predicate,
                args=list(fact.args),
                polarity=fact.polarity,
                modality=fact.modality,
                confidence=fact.confidence,
                source=fact.source,
            )
        return node_id

    def add_fact(self, fact: Fact) -> str:
        fid = self.add_fact_node(fact)
        for prov in fact.provenance:
            sid = self.add_span_node(prov)
            self.g.add_edge(sid, fid, kind="SUPPORTS")
        return fid

    def add_derived_fact(self, fact: Fact, premises: Iterable[Fact], rule_name: str) -> str:
        fid = self.add_fact_node(fact)
        for prov in fact.provenance:
            sid = self.add_span_node(prov)
            self.g.add_edge(sid, fid, kind="SUPPORTS")
        for prem in premises:
            pid = self.add_fact_node(prem)
            self.g.add_edge(pid, fid, kind="DERIVED_FROM", rule=rule_name)
        return fid

    def topological_fact_order(self) -> List[str]:
        return list(nx.topological_sort(self.g))

    def export_json(self, path: str) -> None:
        data = {
            "nodes": [
                {"id": n, **attrs}
                for n, attrs in self.g.nodes(data=True)
            ],
            "edges": [
                {"source": u, "target": v, **attrs}
                for u, v, attrs in self.g.edges(data=True)
            ],
        }
        Path(path).write_text(json.dumps(data, ensure_ascii=False, indent=2), encoding="utf-8")

    def __init__(self, model_name: str = "en_core_sci_scibert", ontology_json: Optional[str] = None):
        self.nlp = spacy.load(model_name)
        if "entity_ruler" not in self.nlp.pipe_names:
            self.entity_ruler = self.nlp.add_pipe("entity_ruler", before="ner")
        else:
            self.entity_ruler = self.nlp.get_pipe("entity_ruler")

        self.ontology = OntologyStore(ontology_json)
        self.graph = KnowledgeDAG()

        self._install_ontology_patterns()
        self.dep_matcher = DependencyMatcher(self.nlp.vocab)
        self._register_dependency_patterns()

    def _install_ontology_patterns(self) -> None:
        patterns = []
        for ent in self.ontology.entities.values():
            for alias in ent.aliases or (ent.canonical,):
                patterns.append({"label": ent.label, "pattern": alias, "id": ent.canonical})
        if patterns:
            self.entity_ruler.add_patterns(patterns)

    # -----------------------------
    # Public API
    # -----------------------------

    def compile(self, text: str, doc_id: str) -> CompilerResult:
        doc = self.nlp(text)
        mentions: List[Mention] = []
        facts: List[Fact] = []

        for sent_id, sent in enumerate(doc.sents):
            prov = SpanRef(
                doc_id=doc_id,
                sent_id=sent_id,
                start_char=sent.start_char,
                end_char=sent.end_char,
                text=sent.text.strip(),
            )

            sent_mentions = self._extract_mentions(doc, sent, prov)
            mentions.extend(sent_mentions)

            sent_facts = self._extract_sentence_facts(doc, sent, prov, sent_mentions)
            facts.extend(sent_facts)

        # Deduplicate facts
        unique: Dict[str, Fact] = {}
        for f in facts:
            unique[f.key()] = f
        facts = list(unique.values())

        # Build DAG
        for f in facts:
            self.graph.add_fact(f)

        # Optional derived layer: you can extend this with config-driven rules.
        self._derive_generic_facts(facts)

        return CompilerResult(
            doc_id=doc_id,
            text=text,
            facts=facts,
            mentions=mentions,
            graph=self.graph.g,
        )

    def export_souffle(self, result: CompilerResult, out_dir: str) -> None:
        out = Path(out_dir)
        out.mkdir(parents=True, exist_ok=True)

        # Generic facts relation:
        # fact(pred, arg1, arg2, polarity, modality, confidence, doc_id, sent_id)
        with (out / "facts.csv").open("w", newline="", encoding="utf-8") as f:
            w = csv.writer(f)
            for fact in result.facts:
                a1 = fact.args[0] if len(fact.args) > 0 else "_"
                a2 = fact.args[1] if len(fact.args) > 1 else "_"
                doc_id = fact.provenance[0].doc_id if fact.provenance else result.doc_id
                sid = fact.provenance[0].sent_id if fact.provenance else -1
                w.writerow([fact.predicate, a1, a2, fact.polarity, fact.modality, fact.confidence, doc_id, sid])

        # Starter Soufflé rules file.
        # Keep it small and generic; domain-specific rules should be added by you later.
        rules = r'''

    # -----------------------------
    # Extraction
    # -----------------------------

    def _extract_mentions(self, doc: Doc, sent: Span, prov: SpanRef) -> List[Mention]:
        out: List[Mention] = []

        # Use NER first
        for ent in doc.ents:
            if ent.start >= sent.start and ent.end <= sent.end:
                canonical = self.ontology.canonicalize_entity(ent.text, ent.label_)
                out.append(
                    Mention(
                        canonical_id=canonical,
                        label=ent.label_,
                        surface=ent.text,
                        start_char=ent.start_char,
                        end_char=ent.end_char,
                    )
                )

        # Fallback: noun chunks for domain concepts if not already captured
        if not out:
            for chunk in sent.noun_chunks:
                text = chunk.text.strip()
                if len(text) < 2:
                    continue
                canonical = self.ontology.canonicalize_entity(text, label="CONCEPT")
                out.append(
                    Mention(
                        canonical_id=canonical,
                        label="CONCEPT",
                        surface=text,
                        start_char=chunk.start_char,
                        end_char=chunk.end_char,
                    )
                )

        # Deduplicate by canonical id + span
        seen = set()
        deduped = []
        for m in out:
            key = (m.canonical_id, m.start_char, m.end_char)
            if key not in seen:
                seen.add(key)
                deduped.append(m)
        return deduped

    def _extract_sentence_facts(self, doc: Doc, sent: Span, prov: SpanRef, mentions: List[Mention]) -> List[Fact]:
        facts: List[Fact] = []
        sent_text = sent.text.lower()

        polarity = self._detect_polarity(sent)
        modality = self._detect_modality(sent)
        confidence = self._estimate_confidence(sent, modality, polarity)

        # Sentence-local mapping from spans to canonical ids
        mention_index = self._index_mentions(mentions)

        # 1) Direct entity typing facts
        for m in mentions:
            if m.label and m.label != "CONCEPT":
                facts.append(
                    Fact(
                        predicate="is_a",
                        args=(m.canonical_id, self.ontology.canonicalize_entity(m.label, label="TYPE")),
                        polarity="positive",
                        modality="asserted",
                        confidence=0.99,
                        provenance=(prov,),
                        source="direct",
                    )
                )

        # 2) Dependency matcher for generic scientific relations
        sent_doc = sent.as_doc()
        matches = self.dep_matcher(sent_doc)

        for match_id, token_ids in matches:
            rule_name = self.nlp.vocab.strings[match_id]
            token_ids = list(token_ids)
            root = sent_doc[token_ids[0]]
            pred = self._predicate_from_rule_or_lemma(rule_name, root)

            subj = self._resolve_subject(root, sent_doc, mention_index)
            obj = self._resolve_object(root, sent_doc, mention_index)

            if subj and obj:
                facts.append(
                    Fact(
                        predicate=pred,
                        args=(subj, obj),
                        polarity=polarity,
                        modality=modality,
                        confidence=confidence,
                        provenance=(prov,),
                        source="direct",
                    )
                )

        # 3) Heuristic lexical fallback for scientific prose
        for tok in sent:
            lemma = tok.lemma_.lower()

            if lemma in self.DEFAULT_RELATION_LEMMAS:
                pred = self.DEFAULT_RELATION_LEMMAS[lemma]
                subj = self._resolve_subject(tok, sent, mention_index)
                obj = self._resolve_object(tok, sent, mention_index)
                if subj and obj:
                    facts.append(
                        Fact(
                            predicate=pred,
                            args=(subj, obj),
                            polarity=polarity,
                            modality=modality,
                            confidence=confidence - 0.05,
                            provenance=(prov,),
                            source="direct",
                        )
                    )

        # 4) A few universal copular/property patterns
        facts.extend(self._extract_copular_facts(sent, prov, mention_index, polarity, modality, confidence))

        return self._dedupe_facts(facts)

    def _extract_copular_facts(
        self,
        sent: Span,
        prov: SpanRef,
        mention_index: Dict[int, str],
        polarity: str,
        modality: str,
        confidence: float,
    ) -> List[Fact]:
        facts: List[Fact] = []

        for tok in sent:
            if tok.lemma_.lower() != "be":
                continue

            subj = self._resolve_subject(tok, sent, mention_index)
            attr = self._resolve_attr(tok, sent, mention_index)

            if not subj or not attr:
                continue

            # If the attribute is adjectival, treat as property; otherwise as is_a.
            attr_tok = self._token_from_canonical(attr, sent)
            if attr_tok is not None and attr_tok.pos_ in {"ADJ"}:
                facts.append(
                    Fact(
                        predicate="has_property",
                        args=(subj, attr),
                        polarity=polarity,
                        modality=modality,
                        confidence=confidence,
                        provenance=(prov,),
                        source="direct",
                    )
                )
            else:
                facts.append(
                    Fact(
                        predicate="is_a",
                        args=(subj, attr),
                        polarity=polarity,
                        modality=modality,
                        confidence=confidence,
                        provenance=(prov,),
                        source="direct",
                    )
                )

        return facts

    # -----------------------------
    # Generic helpers
    # -----------------------------

    def _index_mentions(self, mentions: List[Mention]) -> Dict[int, str]:
        """
        Lightweight char-span index based on sent-local mention spans.
        """
        idx: Dict[int, str] = {}
        for m in mentions:
            # Use start_char/end_char only as a loose map; token resolution below remains heuristic.
            idx[m.start_char] = m.canonical_id
        return idx

    def _predicate_from_rule_or_lemma(self, rule_name: str, root: Token) -> str:
        rule_name = rule_name.upper()
        if rule_name == "COPULA":
            return "is_a"
        if rule_name == "CHARACTERIZED_BY":
            return "characterized_by"
        if rule_name == "INFLUENCED_BY":
            return "influenced_by"
        if rule_name == "ASSOCIATED_WITH":
            return "associated_with"
        if rule_name == "PRECEDES":
            return "precedes"
        if rule_name == "CAUSES":
            return "causes"
        if rule_name == "TREATS":
            return "treats"
        if rule_name == "REQUIRES":
            return "requires"
        if rule_name == "SUPPORTS":
            return "supports"

        lemma = root.lemma_.lower()
        return self.DEFAULT_RELATION_LEMMAS.get(lemma, slugify(lemma))

    def _resolve_subject(self, token: Token, span: Span, mention_index: Dict[int, str]) -> Optional[str]:
        # Prefer dependency subject
        for child in token.children:
            if child.dep_ in {"nsubj", "nsubjpass"}:
                return self._canonical_from_token_or_span(child, span, mention_index)

        # Fallback: nearest entity / noun phrase to the left in the same sentence
        left = self._nearest_content_token_left(token, span)
        if left is not None:
            return self._canonical_from_token_or_span(left, span, mention_index)

        return None

    def _resolve_object(self, token: Token, span: Span, mention_index: Dict[int, str]) -> Optional[str]:
        # Direct object / attribute
        for child in token.children:
            if child.dep_ in {"dobj", "obj", "attr", "oprd"}:
                return self._canonical_from_token_or_span(child, span, mention_index)

        # Prepositional object: by/with/to/of/in/etc.
        for child in token.children:
            if child.dep_ == "prep":
                for gc in child.children:
                    if gc.dep_ == "pobj":
                        return self._canonical_from_token_or_span(gc, span, mention_index)

        # Fallback: nearest content token to the right in the same sentence
        right = self._nearest_content_token_right(token, span)
        if right is not None:
            return self._canonical_from_token_or_span(right, span, mention_index)

        return None

    def _resolve_attr(self, token: Token, span: Span, mention_index: Dict[int, str]) -> Optional[str]:
        for child in token.children:
            if child.dep_ in {"attr", "acomp", "oprd"}:
                return self._canonical_from_token_or_span(child, span, mention_index)
        return self._resolve_object(token, span, mention_index)

    def _canonical_from_token_or_span(self, token: Token, span: Span, mention_index: Dict[int, str]) -> str:
        # First try entity overlap
        for ent in span.ents:
            if ent.start <= token.i < ent.end:
                return self.ontology.canonicalize_entity(ent.text, ent.label_)

        # Fallback: whole token / subtree text
        text = token.text
        if token.ent_iob_ != "O" and token.ent_type_:
            return self.ontology.canonicalize_entity(text, token.ent_type_)
        if token.pos_ in {"PROPN", "NOUN", "ADJ"}:
            return self.ontology.canonicalize_entity(text, label="CONCEPT")
        return self.ontology.canonicalize_entity(text, label="CONCEPT")

    def _token_from_canonical(self, canonical: str, span: Span) -> Optional[Token]:
        for ent in span.ents:
            if self.ontology.canonicalize_entity(ent.text, ent.label_) == canonical:
                # return head token of entity
                return ent.root
        return None

    def _nearest_content_token_left(self, token: Token, span: Span) -> Optional[Token]:
        candidates = [t for t in span if t.i < token.i and t.pos_ in {"NOUN", "PROPN", "ADJ"} and not t.is_stop]
        return candidates[-1] if candidates else None

    def _nearest_content_token_right(self, token: Token, span: Span) -> Optional[Token]:
        candidates = [t for t in span if t.i > token.i and t.pos_ in {"NOUN", "PROPN", "ADJ"} and not t.is_stop]
        return candidates[0] if candidates else None

    def _detect_polarity(self, sent: Span) -> str:
        lower = sent.text.lower()
        if any(m in lower.split() for m in self.NEGATION_MARKERS):
            return "negated"
        # dependency negation
        if any(tok.dep_ == "neg" for tok in sent):
            return "negated"
        return "positive"

    def _detect_modality(self, sent: Span) -> str:
        lower = sent.text.lower()
        for modality, markers in self.MODALITY_MARKERS.items():
            for marker in markers:
                if marker in lower:
                    return modality
        return "asserted"

    def _estimate_confidence(self, sent: Span, modality: str, polarity: str) -> float:
        score = 0.96
        if modality == "probable":
            score -= 0.12
        elif modality == "recommended":
            score -= 0.08
        elif modality == "speculative":
            score -= 0.18
        if polarity == "negated":
            score -= 0.05
        return max(0.5, min(0.99, score))

    def _dedupe_facts(self, facts: List[Fact]) -> List[Fact]:
        seen = set()
        out: List[Fact] = []
        for f in facts:
            k = f.key()
            if k not in seen:
                seen.add(k)
                out.append(f)
        return out

    # -----------------------------
    # Very small derived layer
    # -----------------------------

    def _derive_generic_facts(self, facts: List[Fact]) -> None:
        """
        These are generic, reusable rules. They are not article-specific.
        They live here only as a starter. For serious use, move them to Datalog/Soufflé rules.
        """
        by_pred: Dict[str, List[Fact]] = defaultdict(list)
        for f in facts:
            by_pred[f.predicate].append(f)

        # Example: if something is both age_related and multifactorial -> complex_disease
        age_related = {f.args[0]: f for f in by_pred.get("age_related", []) if len(f.args) >= 1}
        multifactorial = {f.args[0]: f for f in by_pred.get("multifactorial", []) if len(f.args) >= 1}

        for x in set(age_related.keys()) & set(multifactorial.keys()):
            prov = age_related[x].provenance[:1] or multifactorial[x].provenance[:1]
            derived = Fact(
                predicate="complex_disease",
                args=(x,),
                polarity="positive",
                modality="asserted",
                confidence=0.95,
                provenance=prov,
                source="derived",
            )
            self.graph.add_derived_fact(derived, [age_related[x], multifactorial[x]], "R_complex_disease")

        # Example: main_feature + necessary_condition -> diagnostic_hallmark
        main_feature = {(f.args[0], f.args[1]): f for f in by_pred.get("main_feature_of", []) if len(f.args) >= 2}
        necessary = {(f.args[0], f.args[1]): f for f in by_pred.get("necessary_condition_for", []) if len(f.args) >= 2}
        for key in set(main_feature.keys()) & set(necessary.keys()):
            prov = main_feature[key].provenance[:1] or necessary[key].provenance[:1]
            derived = Fact(
                predicate="diagnostic_hallmark",
                args=key,
                polarity="positive",
                modality="asserted",
                confidence=0.94,
                provenance=prov,
                source="derived",
            )
            self.graph.add_derived_fact(derived, [main_feature[key], necessary[key]], "R_diagnostic_hallmark")

    # -----------------------------
    # Public export helpers
    # -----------------------------

    def export_graph_json(self, path: str) -> None:
        self.graph.export_json(path)

    def export_souffle(self, result: CompilerResult, out_dir: str) -> None:
        self._export_souffle_facts(result, out_dir)

    def _export_souffle_facts(self, result: CompilerResult, out_dir: str) -> None:

        # Generic fact relation suitable for Soufflé input.

        facts_path = out / "facts.csv"
        with facts_path.open("w", newline="", encoding="utf-8") as f:

# Приведи пример, как может достигаться конкретная цель, в условиях недостатка знаний в такой системе?

Да — и в такой системе цель достигается не через “полное знание”, а через **постепенное закрытие разрывов**.

Ниже пример в твоей предметной области.

---

## Цель

Допустим, система должна найти путь к цели:

```text
alleviate(bradykinesia)
```

То есть: **как уменьшить выраженность брадикинезии**.

---

## Что уже известно в графе

Пусть в базе уже есть такие факты:

```prolog
symptom(bradykinesia).
disease(ipd).
low_dopamine(ipd).
treatment(dopamine_substitution).
replaces(dopamine_substitution, dopamine).
associated_with(low_dopamine, bradykinesia).
```

И такие правила:

```prolog
restores_dopamine_signal(T) :-
    treatment(T),
    replaces(T, dopamine).

may_alleviate(T, S) :-
    restores_dopamine_signal(T),
    associated_with(low_dopamine, S).
```

---

## Где возникает разрыв знаний

Допустим, у системы **нет прямого факта**:

```prolog
associated_with(low_dopamine, bradykinesia).
```

Тогда она не может сразу доказать цель.
Но она не останавливается — она строит **промежуточный план**.

---

## Как выглядит обратное планирование

### Шаг 1. От цели к подцели

Цель:

```prolog
alleviate(bradykinesia)
```

Правило говорит:

```prolog
may_alleviate(T, bradykinesia) :-
    restores_dopamine_signal(T),
    associated_with(low_dopamine, bradykinesia).
```

Значит, системе нужны две подцели:

1. `restores_dopamine_signal(T)`
2. `associated_with(low_dopamine, bradykinesia)`

---

### Шаг 2. Одна подцель уже решается

`restores_dopamine_signal(T)` раскрывается так:

```prolog
restores_dopamine_signal(dopamine_substitution).
```

потому что есть факт:

```prolog
treatment(dopamine_substitution).
replaces(dopamine_substitution, dopamine).
```

Значит, ветка:

```text
dopamine_substitution
```

уже подходит.

---

### Шаг 3. Вторая подцель пока неизвестна

А вот связь:

```prolog
associated_with(low_dopamine, bradykinesia)
```

отсутствует.

Тогда система не “ломается”, а делает три вещи:

1. помечает это как **gap**;
2. создаёт узел **Hypothesis**;
3. может добавить узел **Experiment / Observation**.

Например:

```text
Hypothesis: low dopamine may contribute to bradykinesia
Experiment: measure dopamine markers in patient subgroup
```

---

## Как это выглядит в DAG

```text
Goal
  ↓
alleviate(bradykinesia)
  ↓
may_alleviate(dopamine_substitution, bradykinesia)
  ↓                     ↘
restores_dopamine_signal  gap: associated_with(low_dopamine, bradykinesia)
  ↓
treatment(dopamine_substitution)
  ↓
replaces(dopamine_substitution, dopamine)
```

То есть:

* одна часть пути уже доказана,
* другая часть пока только гипотеза,
* но план всё равно строится и остаётся полезным.

---

## Что делает система дальше

Если в графе позже появляется новый факт:

```prolog
observed(low_dopamine, patient_group_42).
observed(bradykinesia, patient_group_42).
```

то правило поддержки может сработать:

```prolog
supported_association(low_dopamine, bradykinesia) :-
    observed(low_dopamine, X),
    observed(bradykinesia, X).
```

И тогда gap закрывается.

---

## Какой здесь принцип

Система не требует полного знания заранее.
Она работает так:

1. **цель задаёт направление**;
2. **Datalog выводит известные подцели**;
3. **DAG хранит уже подтверждённые связи**;
4. **неизвестные места становятся гипотезами**;
5. **эксперименты или новые статьи закрывают разрывы**;
6. **план пересчитывается**.

---

## Более общий шаблон

Для любой цели это выглядит так:

```prolog
Goal
  -> Subgoal_1
  -> Subgoal_2
  -> KnownFact
  -> Gap
  -> Hypothesis
  -> Experiment
  -> NewFact
  -> Goal resolved
```

---

## Самое важное

В такой системе **цель достигается не потому, что всё известно**, а потому, что:

* известное используется сразу;
* неизвестное не игнорируется, а оформляется как гипотеза;
* недостающие звенья превращаются в проверяемые шаги.

Это и делает систему живой: она не просто “считает по графу”, а **достраивает знание по мере движения к цели**.
