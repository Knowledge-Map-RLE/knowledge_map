# Изолированный прогноз из пяти карт схемы 6

Сценарий использует готовые неизменяемые карты `text_reified`. Он не запускает извлечение, структурные строки, LLM, переводчик или эмбеддинги. Карты и прежние результаты сравнения сохраняются.

## Исправленное сравнительное представление

`schema6-normalizer-3` отделяет `source_grounded_description` от ограничений факта. Описание остаётся в `auxiliary_attributes`. Для предикатов перехода в деменцию явные процентные границы и запись диапазона получают одну форму. Никакие научные ограничения из-за этого не удаляются. `article-comparator-5` отдельно сохраняет совпавшие атрибуты, полные/частичные отношения и уникальные блоки цели: пары соответствий не считаются отдельными знаниями.

Составные блоки сопоставляются по явным утверждениям и с сохранением логики целого. Если исходный frame объединяет разные мысли одним утверждением, это остаётся диагностикой недостаточной атомизации. Свободная проза не объявляется новым набором доказанных фактов автоматически. Отдельный общий параметр не покрывает всё знание; неизвестный контекст, разные когорты, отрицания и размерности продолжают запрещать эквивалентность.

## Два отдельных процесса

Из административного PowerShell в `api`:

```powershell
poetry run python tools/run_schema6_prediction.py seal --sources <sources-only.json> --output <experiment-directory>
poetry run python tools/run_schema6_prediction.py evaluate --run-id <sealed-run-id> --target <target-reference.json> --output <experiment-directory>
```

Первый вход — только массив точных ссылок `{article_id, pipeline_id, run_id}` на источники. Он не принимает цель, её текст или контрольные цитаты. Запуск связан хешами графов и источников, версиями нормализатора/предиктора, словарём и лимитами. Кандидаты и `seal.json` публикуются атомарно; повторный запуск идемпотентен. Второй процесс проверяет seal и права владельца всех статей, после чего читает целевой запуск. Оценка сохраняется отдельным неизменяемым файлом. Изменённый seal отклоняется.

Обучение, прогноз и оценка разделены по Clean Architecture: домен, сценарии приложения, порты чтения/хранения, файловый адаптер и административный CLI. Квитанции CLI перечисляют фактически прочитанные запуски, без полных текстов и секретов.

## Режимы и ограничения

- `known_union`: все известные атомарные утверждения пятёрки. Это перенос знаний, а не новые выводы.
- `semantic`: статистические шаблоны по совместно встречающимся участникам, без dependency-связей.
- `graph`: шаблоны по полным группам непосредственных предпосылок. Альтернативные группы не объединяются.

Новая гипотеза требует поддержки двух разных статей, одного заключения и до трёх атомарных предпосылок. Обобщаются участники и переменная локальной когорты; применение когортного шаблона остаётся внутри одного источника с восстановлением конкретной области. Числа, отрицания, модальность, действие/намерение, время и ограничения не обобщаются. Неизвестный контекст, циклические участники и неподходящая логика исключают обучение; исходные утверждения сохраняются в базовом режиме.

До двадцати новых гипотез на режим. Поиск без связей ограничен двенадцатью соседями; связывание — тысячей комбинаций на правило. Диагностика сохраняет ограничения и пропуски. Пустой результат допустим. Отсутствие утверждения в цели не является опровержением.

## Оценка и честная интерпретация

Полные компоненты, покрытие всего блока, частичные отношения и общие параметры учитываются раздельно. Для цитирования различаются контрольный фрагмент, абзац с неразрешённой областью цитаты и отсутствие прямой ссылки на пятёрку. Последнее не доказывает новизну относительно остальной литературы.

PMC10000452 уже использовалась для разработки. Разделение процессов доказывает изоляцию входов предиктора, но не превращает знакомый отладочный случай в независимое проспективное испытание. После фиксации правил нужна другая, ранее не использованная цель. Разметка Codex и автоматическое совпадение требуют экспертной научной проверки.

Артефакты: `eval/schema6_prediction/pmc10000452-five-sources/<run_id>`. Исправленное сравнение сохраняется новым результатом в Neo4j и доступно в существующей вкладке «Сравнение статей». Отчёт HTML автономен; научные тексты английские, элементы интерфейса русские/английские. Кэшированные русские карты доступны в сравнении без переводчика. API — 8000, клиент — 5555; перезапуск выполняет пользователь по AGENTS.md. AI-сервис не меняется, Git-коммиты не создаются.
