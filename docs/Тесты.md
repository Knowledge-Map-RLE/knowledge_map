# Карта Знаний. Тесты

Здесь собраны тесты для того что бы удостовериться что Карта Знаний действительно работает.

- Системный обзор является результатом статей его составляющий. Нужно получать его автоматически из этих статей и сравнивать его с тем что сделали учёные
- Можно брать сообщения в соцсетях учёных о том какие научные выводы они считают правильнмы и таким образомсверять с ними результаты алгоритмов Карты Знаний. Примеры: Пётр Лидский, Пётр Федичев (ещё одна причина вести медиа деятельность учёным, для КЗ по сути польза как и для ИИ)
- Проверить алгоритм достижения цели на тех целях на которых он был обучен и на тестовой выборке
