# Промпт LLM-извлечения структуры блоков из научной статьи (русский перевод)

> Русский перевод unified one-stage промпта из `api/services/llm_triplet_extraction_prompt_en.py`.
> Используется только для справки — в коде используется только английская версия.

---

Ты — эксперт по представлению знаний (knowledge representation). Извлеки структурированные блоки знаний из научной статьи ниже.

# Задача

Извлеки ВСЕ блоки знаний из полной статьи. Выведи контейнерные блоки (T1–T59) и атомарные T4-триплеты в одном JSON-ответе.

# Вход

Полная статья: «__ARTICLE_TITLE__»

--- НАЧАЛО СТАТЬИ ---
__ARTICLE_TEXT__
--- КОНЕЦ СТАТЬИ ---

# Каталог типов блоков

Выводи ТОЛЬКО эти типы и поля (пустые опускай):

- **1 Метаданные** (МЕТА-УТВЕРЖДЕНИЕ — содержит ВСЕХ авторов): `doi`, `title`, `authors` (ПОЛНЫЙ массив — каждый автор из статьи, не сокращённый). Только один раз. Это мета-блок: представляет всю статью как единую сущность. Все имена авторов должны быть включены.
- **2 Цель исследования** (допускается несколько, до 8): `subject` (2-3 слова), `predicate` (1-2 слова, напр. «цель», «направлено на»), `object` (3-8 слов — ОДНА атомарная подцель, НЕ сложное предложение). Разбивай сложные цели на несколько T2-блоков с `dependsOn` (массив тегов `{Bn}` к.setViewport к T2-блокам-предпосылкам). Пример: «пересмотреть маркеры рака» → T2, «предложить маркеры старения» → T2 (dependsOn: ["{B2}"]), «различить ограничивающие жизнь маркеры» → T2 (dependsOn: ["{B3}"]). Каждый object у T2 должен быть КОРОТКИМ утверждением — если цель состоит из нескольких частей, разбей на отдельные T2-блоки.
- **7 Гипотеза** (МЕТА-УТВЕРЖДЕНИЕ — краткое): `hypothesis` (1-2 предложения МАКСИМУМ — основная гипотеза, НЕ подробное объяснение), `disproofExplanation` (1-2 предложения МАКСИМУМ). Это мета-блок: держи КОРОТКИМ. Подробные факты о гипотезе разлагаются в T4-триплеты, ссылающиеся на этот блок через тег `{Bn}`.
- **14 Эксперимент** (ОБЯЗАТЕЛЬНЫЙ — каждая статья должна содержать минимум 1): `experimentName`, `experimentType` (выбери: Поведенческий, Гистология, RNA-seq, Интервенция in vivo, In vitro, Вычислительный, Обзор-синтез), `outcomes` (массив), `steps` (массив тегов `{Bn}` → T56 — ОБЯЗАТЕЛЬНЫЙ), `findings` (массив тегов `{Bn}` → T57 — ОБЯЗАТЕЛЬНЫЙ), `duration`, `experimentalPairs` (массив объектов `{"groupRef": "{Bn}"}` → T55 экспериментальные группы — ОБЯЗАТЕЛЬНЫЙ), `controlPairs` (массив объектов `{"groupRef": "{Bn}"}` → T55 контрольные группы — ОБЯЗАТЕЛЬНЫЙ, если есть контрольная группа). Для обзорных статей: создай T14 с experimentType="Обзор-синтез".
- **16 Биологический механизм**: `mechanism` (текст).
- **18 Интервенция**: `intervention`, `dosage`, `dosageRegimen`.
- **19 Животная модель**: `species`, `timeline`, `conditions`.
- **20 Выводы**: `conclusions`.
- **22 Сущность**: `subject`, `predicate`, `object` (текст).
- **23 Определение понятия**: `term`, `definition`.
- **27 p-value**: `pValue` (число). Один блок на каждое уникальное значение p.
- **37 Статистическая обработка**: `statProcessing`, `expectationsComparison`.
- **38 Утверждение**: `claimSubject`, `claimPredicate` (один из: является, вызывает, ингибирует, активирует, коррелирует с, влияет на, связано с, определяет, содержит, участвует в, модулирует, нейтрализует, предотвращает, индуцирует, приводит к, требует, зависит от, запускает, подавляет, усиливает, способствует, нарушает), `claimObject`, `confidenceNotes`, `isNegated` (true/false).
- **39 Ограничения исследования**: `limitations`.
- **40 Побочные выводы/гипотезы**: `sideFindings`.
- **44 Новизна**: `novelty`.
- **46 Будущие исследования**: `futureResearch`.
- **47 Ссылки на предыдущие исследования**: `references`.
- **51 Финансирование**: `funding`.
- **54 Действие**: `subject` (2-3 слова), `predicate` (1-2 слова), `object` (2-3 слова). Только краткие именные фразы.
- **55 Группа животных**: `groupName`, `n`, `conditions`, `purpose`.
- **56 Шаг эксперимента**: `stepName`, `details`, `duration`.
- **57 Результат (находка)**: `parameter`, `direction` (повышено/понижено/без изменений/тренд), `significance` (significant/non-significant/trend), `pValue` (тег `{Bn}` блока T27 ИЛИ число), `figureRef` (напр. «Рис. 1F»), `detail`, `interventionRef` (тег `{Bn}` → T18/T54 — ОБЯЗАТЕЛЬНЫЙ, если этот результат получен в результате интервенции; опускай только для наблюдательных находок), `outcomeClass` (positive/negative/neutral).
- **58 Зависимость действий** ⭐ (КРИТИЧЕСКИЙ для анализа паттернов): `source` (краткий текст, 2-5 слов, напр. «гиперфункция mTOR»), `target` (краткий текст, 2-5 слов, напр. «клеточное старение»), `relationType` (один из: causes, enables, requires, precedes, inhibits, prevents, leads_to, enhances, suppresses), `confidence` (high/medium/low), `evidence` (КРАТКОЕ текстовое описание подтверждающего факта, 3-8 слов — НЕ тег `{Bn}`, поскольку T4 не имеют тегов).
- **59 Временная связь**: `earlier` (тег `{Bn}` → T56/T54 — ДОЛЖЕН существовать в этом ответе), `later` (тег `{Bn}` → T56/T54 — ДОЛЖЕН существовать в этом ответе), `relationType` (precedes/follows/during). Выводи T59 ТОЛЬКО если ОБА ссылочных блока существуют. Не ссылайся на T4-блоки (они используют `{SEQn}`, не `{Bn}`).

# T1 Метаданные — МЕТА-УТВЕРЖДЕНИЕ

T1 — мета-блок, представляющий всю статью. Должен содержать:
- `doi`: DOI из статьи
- `title`: полное название
- `authors`: ПОЛНЫЙ массив ВСЕХ имён авторов — НЕ сокращай и не опускай никого. Включи каждого автора, указанного в статье.

T1 резолвится сервисом в UUIDv8. Все ссылки на T1 используют тег `{Bn}`.

# T2 Цели исследования — ДОПУСКАЕТСЯ НЕСКОЛЬКО, РАЗЛАГАЮТСЯ В ТРИПЛЕТЫ

Разбивай сложные исследовательские цели на отдельные T2-триплетные блоки с зависимостями.

Каждая T2 должна быть ОДНОЙ атомарной целью (3-8 слов в `object`). Если статья говорит «мы стремимся к X, Y и Z», создай ТРИ T2-блока:
- T2: subject="мы", predicate="цель", object="X"
- T2: subject="мы", predicate="цель", object="Y", dependsOn=["{Bn_X}"]
- T2: subject="мы", predicate="цель", object="Z", dependsOn=["{Bn_Y}"]

Поле `dependsOn` (массив тегов `{Bn}`) отражает декомпозицию целей: какие подцели должны быть достигнуты до этой. Если цель не имеет предпосылок, опускай `dependsOn`.

Обычно в статье 3-8 T2-блоков (не только 2-4 сложных).

Примеры для статьи о старении в колючих мышах:
- T2({B2}): subject="мы", predicate="цель", object="определить механизмы резистентности к старению"
- T2({B3}): subject="мы", predicate="цель", object="проверить роль кластерина в inflammaging", dependsOn=["{B2}"]
- T2({B4}): subject="мы", predicate="цель", object="охарактеризовать иммунометабиологию", dependsOn=["{B2}"]
- T2({B5}): subject="мы", predicate="цель", object="найти мишени для лекарств", dependsOn=["{B3}", "{B4}"]

# T7 Гипотеза — МЕТА-УТВЕРЖДЕНИЕ (КОРОТКАЯ)

T7 — мета-блок. Поле `hypothesis` должно содержать 1-2 предложения МАКСИМУМ — ОСНОВНОЕ утверждение, НЕ подробное объяснение. Поле `disproofExplanation` тоже 1-2 предложения МАКСИМУМ.

Держи T7 КОРОТКОЙ, потому что подробные факты о гипотезе разлагаются в T4-триплеты, ссылающиеся на T7 через тег `{Bn}`. Не пиши длинное объяснение в T7.

# T14 Эксперименты — ОБЯЗАТЕЛЬНЫЕ ССЫЛКИ НА ШАГИ

Каждая T14 должна содержать:
- `steps`: массив тегов `{Bn}` → T56-блоки (шаги этого эксперимента)
- `findings`: массив тегов `{Bn}` → T57-блоки (результаты этого эксперимента)
- `experimentalPairs`: массив объектов `{"groupRef": "{Bn}"}` → T55-блоки экспериментальных групп
- `controlPairs`: массив объектов `{"groupRef": "{Bn}"}` → T55-блоки контрольных групп (опускай, если нет контрольной группы)

Цепочка связей ДОЛЖНА быть полной: T14 → T55 группы + T56 шаги + T57 результаты + T18 интервенции.

Если ты не можешь сослаться на конкретные T56/T57 блоки (потому что они ещё не выведены), выведи T56/T57 блоки СНАЧАЛА, затем сослаться на них в T14. Порядок вывода: T55 группы, T18 интервенции, T56 шаги, T57 результаты — ДО T14, которая на них ссылается.

Для обзорных статей (experimentType="Обзор-синтез"): experimentalPairs/controlPairs можно опустить, поскольку нет экспериментальных групп.

# Теги {Bn} → Резолв UUID

Ты выводишь теги `{Bn}` (например `{B1}`, `{B15}`) как ссылки между блоками. Сервис резолвит эти теги в реальные UUIDv8 после извлечения. Тебе НЕ нужно генерировать UUID — просто используй consistent теги `{Bn}`.

Правила для {Bn} ссылок:
- Каждый `{Bn}`, на который ты ссылаешься, должен быть выведен в этом же ответе как блок с `"tag": "{Bn}"`.
- T4-блоки НЕ имеют тега — они идентифицируются по позиции и получают UUID через `{SEQn}`.
- Не вкладывай объекты блоков внутрь полей — только строки-теги вида `"{B1}"`.

# T57 Результаты — ОБЯЗАТЕЛЬНАЯ ССЫЛКА НА ИНТЕРВЕНЦИЮ

Каждый T57-результат ДОЛЖЕН ссылаться на свой источник:
- Если результат получен в результате интервенции (лекарство, лечение, процедура — должен быть T18 или T54 блок): `interventionRef` = тег `{Bn}` → T18 или T54 блок — ОБЯЗАТЕЛЬНЫЙ
- Если результат из наблюдательного эксперимента (поведенческий тест, гистология, RNA-seq, секвенирование) БЕЗ интервенции: ОПУСКАЙ `interventionRef` полностью
- Если у результата есть p-value: `pValue` = тег `{Bn}` → T27 блок — ОБЯЗАТЕЛЬНЫЙ
- `parameter` (2-5 слов): измеряемая переменная или исход (напр. «сила хвата», «уровень IL-1β»)
- `direction`: increased / decreased / no change / trend
- `significance`: significant / non-significant / trend
- `outcomeClass`: positive / negative / neutral

Пример С интервенцией: лечение кластерином улучшает силу хвата → T57(parameter="сила хвата", direction="increased", significance="significant", interventionRef="{Bn_кластерин_T18}", pValue="{Bn_pvalue_T27}", outcomeClass="positive")

Пример БЕЗ интервенции (наблюдательный): старые A. russatus не показывают изменений в вертикальном стоянии → T57(parameter="вертикальное стояние", direction="no change", significance="significant", figureRef="Рис. 1F", outcomeClass="positive")

**interventionRef ОБЯЗАН ссылаться на T18 или T54 блок — НИКОГДА на T37, T56 или другой тип.**
- T18 = само вещество/процедура (напр. «рекомбинантный мышиный кластерин»)
- T54 = действие/процесс (напр. «кластерин → подавляет → inflammaging»)
- T56 = ШАГ эксперимента (напр. «вводить кластерин ежедневно») — это НЕ интервенция, не ссылайся на него из T57
- Если нет T18/T54 интервенции, опускай interventionRef

# T58 Зависимости действий — КРИТИЧЕСКИЙ

**T58 — самый важный тип блоков для downstream-анализа.** Каждая каузальная, enabling или inhibitory связь между биологическими действиями, механизмами и исходами ДОЛЖНА быть записана как T58-блок.

**Когда создавать T58:**
- Текст говорит X «вызывает», «приводит к», «результатом является», «управляет», «способствует» Y
- Текст говорит X «ингибирует», «подавляет», «предотвращает», «блокирует» Y
- Текст говорит X «необходим для», «обеспечивает», «обязателен для» Y
- Текст говорит X «предшествует» Y в биологическом каскаде
- Текст говорит X «усиливает», «амплифицирует» Y
- Любая механическая связь между сущностями на разных иерархических уровнях

**Примеры:**
- «старение → приводит к → inflammaging» → T58(source="старение", target="inflammaging", relationType="causes", evidence="старение повышает воспалительные маркеры")
- «гиперфункция mTOR → приводит к → болезни возрастного характера» → T58(source="гиперфункция mTOR", target="болезни возрастного характера", relationType="leads_to", evidence="активация mTOR управляет патологиями")
- «рапамицин → ингибирует → mTOR» → T58(source="рапамицин", target="mTOR", relationType="inhibits", evidence="рапамицин блокирует mTOR-сигналинг")

**Приоритет:** T58-блоки ВЫСОКОГО приоритета. Извлекай их даже при неуверенности (используй confidence=medium/low). Пропускать каузальную связь хуже, чем извлечь слабую.

**source, target и evidence должны быть КОРОТКИМ ТЕКСТОМ (2-5 слов каждый), НЕ ссылками `{Bn}`.**

# T59 Временные связи

Записывай временные последовательности между шагами эксперимента или биологическими событиями. ОБА поля `earlier` и `later` должны быть тегами `{Bn}` блоков, которые существуют в этом ответе (обычно T56 шаги или T54 действия).

- «сначала X, потом Y» → T59(earlier=`{Bn_X}`, later=`{Bn_Y}`, relationType="precedes")
- «X происходит во время Y» → T59(earlier=`{Bn_Y}`, later=`{Bn_X}`, relationType="during")

**Не создавай T59 если:** ссылочные блоки не существуют, или если пришлось бы ссылаться на T4-блоки (T4 используют `{SEQn}`, не `{Bn}`). Пропускай T59 вместо создания сломанных ссылок.

# Правила декомпозиции

Один T4-триплет = один простой факт (субъект → предикат → объект). Каждый из S/P/O — 1-3 слова, кроме неделимых терминов.

**Предикаты (семантическая роль):** `кого`/`что`/`какой`/`какой вид`/`где`/`когда`/`сколько`/`как долго`/`для чего`/`в чём`/`из чего`/`с чем`/`к чему`/`после чего`/`до чего`.

**Перекрёстные ссылки:** когда термин уже разложен T4-триплетом в этом ответе, ссылайся на него как `{SEQn}` (n = порядковый номер этого триплета в массиве блоков). ~20-30% T4-триплетов должны содержать такие ссылки.

**Декомпозиция по типу контейнера:**
- **T1 (Метаданные)**: разложить в T4-триплеты об авторах, DOI, названии, журнале. Обычно 3-5. Каждый T4 ссылается на T1 через тег контейнера.
- **T7 (Гипотеза)**: разложить гипотезу на отдельные утверждения. Обычно 5-10 T4-триплетов, покрывающих основное утверждение, доказательства и логику опровержения.
- **T56 (Шаг)**: каждый элемент процедуры → отдельный триплет. Обычно 5-10.
- **T57 (Результат)**: раскрыть параметр, группу, направление, значимость, p, рисунок. Обычно 3-6.
- **T19 (Модель)**: вид + условия + продолжительность жизни. Обычно 3-5.
- **T38 (Утверждение)**: субъект/предикат/объект + уверенность + область. Обычно 3-5.
- **T14 (Эксперимент)**: название + тип + каждый включённый тест. Обычно 2-5.

# Ожидаемый масштаб (обзорная статья ~275 строк)

- T1 метаданные: 1
- T2 цели: 4-8 (разложенные триплеты с dependsOn)
- T7 гипотеза: 1
- T4 триплеты: 15-25
- T22 сущности: 5-10
- T38 утверждения: 6-12
- T54 действия: 3-5 (краткие: 2-3 слова на поле)
- T58 зависимости действий: 12-20
- T59 временные: 3-8 (только для существующих T56/T54 блоков)
- T14 эксперименты: 3-8 (ОБЯЗАТЕЛЬНО, включая Обзор-синтез для обзорных статей)
- T56 шаги: 15-30
- T57 результаты: 20-50
- T55 группы: 10-25
- T19 модели: 5-15

# Порядок вывода

1. T1 Метаданные
2. T2 Цели (все)
3. T7 Гипотеза
4. T19 Животные модели, T55 Группы
5. T56 Шаги → T57 Результаты → T27 p-values (ДО T14)
6. T14 Эксперименты (с тегами на T56/T57 из шага 5)
7. T54 Действия → T58 Зависимости действий
8. T59 Временные связи
9. T22 Сущности, T23 Определения
10. T38 Утверждения
11. T16 Механизмы, T18 Интервенции
12. T37 Статистика
13. T39/T40/T44/T46/T47 Элементы обсуждения
14. T51 Финансирование
15. T4 Атомарные триплеты (последние, ссылаются на всё вышеперечисленное через теги `{Bn}`)

Только JSON, без пояснений:

# Жёсткие правила

1. Каждый `{Bn}`, на который ссылаешься в data, должен существовать как тег в этом ответе.

3. Не выводи дублирующие блоки для одной и той же сущности/шага/результата.
4. Числовые результаты (p-value, n, годы, проценты) НЕ должны теряться.
5. Не выводи T54 для авторских вкладов (роли CRediT).
6. Никакого markdown, никаких пояснений вне JSON.
7. Массивы steps/findings в T14 ОБЯЗАТЕЛЬНЫ — каждый эксперимент должен ссылаться на свои шаги и результаты.
