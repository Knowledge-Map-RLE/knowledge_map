# LLM vs. NLP-пайплайн: сравнение качества и стоимости на 30 миллионах статей

## Контекст проекта

Проект «Карта Знаний» — построение направленного ациклического графа (DAG) всех релевантных знаний о биологии, медицине и механизмах старения, с конечной целью радикального продления жизни через омоложение. Источник данных: ~30 000 000 научных статей (PubMed, PMC, bioRxiv и др.). Задачи: NER, извлечение отношений, парсинг зависимостей, семантические эмбеддинги → RDF/DAG.

## 4. Сравнение качества: LLM vs. специализированные NLP-модели на биомедицинских задачах

### 4.1 Named Entity Recognition (NER)

| Модель / Подход | Тип | F1 (биомед. NER) | Примечание |
|---|---|---|---|
| PubMedBERT (fine-tuned) | Специализированный | **87–90** | SOTA на BLURB |
| OpenMed NER (DeBERTa-v3) | Специализированный | **90+** | SOTA на 10/12 бенчмарков |
| GPT-4o (zero-shot) | Общий LLM | 55–70 | Сильно варьирует по типу сущностей |
| GPT-5.4 (few-shot) | Общий LLM | 65–78 | Улучшение, но не SOTA |
| Claude Opus 4.6 (few-shot) | Общий LLM | 65–80 | Сильный instruction following |
| Gemini 3.1 Pro (few-shot) | Общий LLM | 60–75 | Хорошо на длинных текстах |
| DeepSeek V3/V4 (zero-shot) | Общий LLM | 55–70 | Сравнимо с ранними GPT-4 |
| GLiNER-biomed (zero-shot) | Специализированный compact | **~60** | Без обучения, 140x меньше GPT |
| SciSpaCy | Традиционный NLP | 79–80 | Базовая линия |

**Вывод:** Файнтюнённые специализированные модели превосходят LLM общего назначения на **10–25 пунктов F1** в биомедицинском NER. LLM проигрывают на структурированном извлечении, где нужна точная граница сущности.

### 4.2 Извлечение отношений (Relation Extraction)

| Модель / Подход | F1 (биомед. RE) | Примечание |
|---|---|---|
| REBEL (fine-tuned на BioRED) | **~85–92** | Прямой вывод троек |
| PL-Marker + SciBERT | **~37** (SciERC) | Трудная задача, но SOTA |
| DeepSeek V3 (zero-shot) | **~84** (F1 на RE) | Неожиданно сильный |
| MedGemma-27B | **~82** | Доменно-адаптированный |
| GPT-4o (zero-shot) | **~71** | Высокая точность, низкий recall |
| GPT-4.1 (zero-shot) | **~73** | Аналогично — консервативный bias |

**Вывод:** На задаче RE LLM показывают конкурентные результаты. DeepSeek V3 продемонстрировал лучшее согласие с экспертной разметкой (Cohen's Kappa 0.730), чем GPT-4o (0.561) и GPT-4.1 (0.597). Доменно-адаптированные модели (MedGemma) ещё лучше. Файнтюнённый REBEL остаётся лидером при наличии обучающих данных.

### 4.3 Общий паттерн из исследований (BioNLP 2025–2026)

Консенсус научного сообщества чётко разделяет две ситуации:

**Извлекательные задачи (NER, RE, классификация):** файнтюнённые доменные трансформеры (PubMedBERT, BioBERT) стабильно превосходят LLM общего назначения. Преимущество: +10–25 F1 на NER, +5–15 F1 на RE.

**Генеративные задачи (QA, суммаризация, рассуждение):** LLM общего назначения лидируют. Med-Gemini достигает 91.1% на MedQA, GPT-5 ~86% на USMLE. Здесь LLM не имеют конкурентов среди мелких моделей.

## 6. Ключевые выводы

### По стоимости

1. **Бюджетные LLM (DeepSeek, Grok, Gemini Flash-Lite) дешевле NLP-пайплайна** — $27 000–60 000 vs. $100 000+. Но качество на структурированных задачах ниже на 15–30 пунктов F1.

2. **Flagship LLM запредельно дороги на масштабе 30M статей** — Claude Opus 4.6 стоит $1.5M, GPT-5.4 — $825K. Даже с Batch API это $400K–750K. Для данного масштаба это не оправдано.

3. **Prompt caching и Batch API критически важны** — дают суммарную экономию 50–60% для любой LLM-стратегии.

4. **Самый экономичный LLM: Gemini 2.5 Flash-Lite** ($13 500 с batch) — но при значительном компромиссе по качеству.

### По качеству

5. **Для NER (ваша ключевая задача): файнтюнённые модели побеждают LLM однозначно.** PubMedBERT/OpenMed NER дают F1 87–90+, лучшие LLM — 65–80. Разница в 10–25 пунктов — это тысячи пропущенных или неверно извлечённых сущностей на каждые 100 000 статей.

6. **Для RE: LLM конкурентны, но не лидируют.** DeepSeek V3 показал впечатляющие F1 84, но REBEL fine-tuned достигает 85–92.

7. **Уникальная сила LLM — гибкость схемы.** Когда вам нужно извлечь сущности типа «механизм омоложения», «путь обхода старения», «интервенция в эпигенетическое репрограммирование» — ни одна предобученная модель это не сделает. LLM сделает это из промпта.

### Итоговая рекомендация

**Для «Карты Знаний» на 30M статей с целью построения DAG омоложения: гибридный подход (Сценарий C).** NLP-пайплайн для массового извлечения с максимальной точностью, LLM для кастомных задач, обогащения схемы и онтологического рассуждения. Общий бюджет: **$107 000–220 000**. Качество: F1 87–92 на стандартных задачах + покрытие уникальных доменных отношений через LLM.

Альтернатива для минимального бюджета: чистый DeepSeek V4 на всё за **$60 000** — но с потерей ~15–25 пунктов F1 на NER и необходимостью ручной пост-обработки значительной части результатов.


## Дима, вот ключевые выводы из исследования:

**Масштаб поражает.** 30 миллионов статей — это 150 миллиардов входных токенов. На Claude Opus 4.6 это стоит **$1.5 миллиона**. На GPT-5.4 — $825K. Даже с Batch API (-50%) flagship-модели обойдутся в $330K–750K.

**Неожиданный результат:** бюджетные LLM (DeepSeek V4, Gemini Flash-Lite, Grok) оказываются **дешевле NLP-пайплайна** — $27K–60K vs. $100K–200K за GPU-инфраструктуру. Но качество на NER проседает на 15–25 пунктов F1, что на 30M статей означает миллионы пропущенных сущностей.

**По качеству LLM проигрывают на структурированном извлечении.** Информационно-извлекательные задачи (NER, RE) до сих пор лучше решаются файнтюнёнными доменными моделями, тогда как LLM общего назначения лидируют в задачах рассуждения и QA. PubMedBERT даёт F1 87–90 vs. 65–80 у лучших LLM на biomedical NER.

Интересно, что DeepSeek-V3 показал лучшее согласие с экспертной разметкой на извлечении отношений (Cohen's Kappa 0.730), превзойдя GPT-4o (0.561) и GPT-4.1 (0.597) — при цене в 30–50 раз ниже.

**Моя рекомендация — гибридный подход:** NLP-пайплайн для массового прогона 30M статей (F1 87–92), а LLM точечно для кастомных задач вроде извлечения «механизмов омоложения» и «путей обхода старения», которые ни одна предобученная модель не знает. Итоговый бюджет: **$107K–220K** — сравнимо с чистым NLP, но с намного более богатым DAG.
