# Загрузка и сохранение данных в базу данных

## Доступные воркеры

- PubMed baseline FTP (загрузчик статей, сохранение в Neo4j базу данных)

## Локальный запуск (Poetry)

1) Требования: установлен Poetry, запущен Neo4j (`bolt://127.0.0.1:7687`).

2) Установка зависимостей:

```
poetry install
```

3) Загрузка одного XML.gz файла (предпоследнего в каталоге `data/PubMed` относительно корня репозитория):

```
poetry run python pubmed_baseline_ftp_to_db.py
```

4) Проверка статистики в БД:

```
poetry run python analyze_database.py
```

Примечание: скрипт загрузки временно настроен на обработку одного файла и выполняет полную очистку БД через APOC перед загрузкой.

## Перенос исходного Markdown

Скрипт `migrate_raw_markdown_storage.py` переносит ссылки Neo4j со старого свойства `docling_raw_md_s3_key` на `raw_markdown_s3_key` и переименовывает объекты в S3 в `{doc_id}_raw.md`.

Сначала выполните безопасный просмотр плана:

```powershell
poetry run python migrate_raw_markdown_storage.py
```

Для применения миграции нужны `NEO4J_URI`, `NEO4J_USERNAME`, `NEO4J_PASSWORD` и параметры S3 из окружения. `--apply` запускайте только в согласованное окно обслуживания после остановки старых писателей и переключения потребителей. Скрипт копирует объект, сверяет размер и SHA-256, обновляет Neo4j и удаляет старый объект только после проверки. При прерывании повторный запуск завершает очистку объектов с временным маркером.
