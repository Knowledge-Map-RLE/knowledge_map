# Промпт. Сделай active learning для разметки статей

Для твоей задачи я бы делал **pool-based active learning**: сначала немного золотой разметки, потом модель выбирает **самые неуверенные** примеры, а в батче — ещё и **разнообразные**, чтобы не та([Scikit-learn][1])учай, где uncertainty sampling и batch diversity дают хороший выигрыш. ([Springer Nature Link][2])ческая схема и рабочий каркас кода.

### Схема для твоего кейса

1. Сначала размечаешь вручную маленькое ядро: примерно 200–500 статей или фрагментов.
2. Обучаешь по отдельности три модели:

   * `goal_type` — успешная / неуспешная цель,
   * `span_label` — фрагмент текста,
   * `relation` — связь `ведёт к`.
3. Прогоняешь модель по неразмеченному пулу.
4. Берёшь примеры, где модель **меньше всего уверена**.
5. Из этих примеров выбираешь **разнообразный батч**, чтобы не размечать дубликаты.
6. Человек проверяет только этот батч.
7. Дообучаешься и повторяешь цикл.

## Рабочий каркас на Python

Ниже пример для классификации фрагментов текста. Его можно потом повторить отдельно для целей и для отношений.

```python
from __future__ import annotations

from dataclasses import dataclass
from typing import List, Tuple
import numpy as np

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.metrics.pairwise import cosine_similarity


@dataclass
class LabeledExample:
    text: str
    label: int


class ActiveLearningTextClassifier:
    def __init__(self):
        self.vectorizer = TfidfVectorizer(
            max_features=50000,
            ngram_range=(1, 2),
            min_df=2
        )
        self.model = LogisticRegression(max_iter=2000)

    def fit(self, labeled: List[LabeledExample]) -> None:
        texts = [x.text for x in labeled]
        labels = [x.label for x in labeled]
        X = self.vectorizer.fit_transform(texts)
        self.model.fit(X, labels)

    def predict_proba(self, texts: List[str]) -> np.ndarray:
        X = self.vectorizer.transform(texts)
        return self.model.predict_proba(X)

    def query_batch(
        self,
        pool_texts: List[str],
        batch_size: int = 20,
        uncertainty_top_n: int = 200,
        diversity_lambda: float = 0.7
    ) -> List[Tuple[int, str, float]]:
        """
        Возвращает список (index, text, score), где score = uncertainty.
        Сначала берём наиболее неуверенные примеры, потом фильтруем по разнообразию.
        """
        proba = self.predict_proba(pool_texts)

        # uncertainty = 1 - max_class_probability
        uncertainty = 1.0 - np.max(proba, axis=1)

        # сначала берём top-N самых неуверенных
        candidate_idx = np.argsort(-uncertainty)[:uncertainty_top_n]
        candidate_texts = [pool_texts[i] for i in candidate_idx]

        # матрица TF-IDF для diversity
        Xcand = self.vectorizer.transform(candidate_texts)
        sim = cosine_similarity(Xcand)

        selected_local = []
        selected_global = []

        # greedy MMR-like selection
        remaining = set(range(len(candidate_idx)))

        while remaining and len(selected_local) < batch_size:
            best_i = None
            best_score = -1e9

            for i in list(remaining):
                unc = uncertainty[candidate_idx[i]]

                if not selected_local:
                    diversity_penalty = 0.0
                else:
                    diversity_penalty = max(sim[i, j] for j in selected_local)

                score = diversity_lambda * unc - (1 - diversity_lambda) * diversity_penalty

                if score > best_score:
                    best_score = score
                    best_i = i

            selected_local.append(best_i)
            selected_global.append(
                (int(candidate_idx[best_i]), pool_texts[int(candidate_idx[best_i])], float(uncertainty[int(candidate_idx[best_i])]))
            )
            remaining.remove(best_i)

        return selected_global


if __name__ == "__main__":
    labeled = [
        LabeledExample("This study shows that pesticide exposure increases Parkinson's risk.", 1),
        LabeledExample("The experiment was conducted on mice.", 0),
        LabeledExample("Oxidative stress contributes to neuronal death.", 1),
        LabeledExample("The article discusses related work.", 0),
    ]

    pool = [
        "Environmental factors may contribute to disease progression.",
        "References are listed at the end of the paper.",
        "Dopaminergic neurons are affected by toxic exposure.",
        "The methodology section describes the dataset.",
        "Mitochondrial dysfunction leads to oxidative stress.",
    ]

    clf = ActiveLearningTextClassifier()
    clf.fit(labeled)

    batch = clf.query_batch(pool, batch_size=3, uncertainty_top_n=5)
    for idx, text, score in batch:
        print(idx, round(score, 4), text)
```

## Как это применить именно к твоей разметке

Для твоего проекта я бы сделал **три отдельных active-learning цикла**:

### 1) `goal_type`

Классифицирует цель как:

* успешная
* неуспешная

### 2) `span_role`

Размечает куски текста:

* фрагмент, способствующий успеху
* фрагмент, способствующий неуспеху
* всё остальное

### 3) `relation_extraction`

Определяет связь:

* `ведёт к`

Так проще, чем пытаться обучить одну монолитную модель на всё сразу.

## Как брать фрагменты для разметки

У тебя уже есть spaCy-разметка, значит хороший вариант такой:

1. spaCy даёт кандидатов на сущности и spans.
2. Модель оценивает уверенность по каждому кандидату.
3. Active learning выбирает:

   * самые неуверенные,
   * и среди них самые разные по тексту.

## Практический старт

Если делать по-умному, то я бы начал так:

* 300–500 примеров вручную
* 1 базовая модель на каждый тип задачи
* 20–50 новых примеров на итерацию
* 5–10 итераций

Это обычно уже даёт заметный прирост качества без разметки миллионов статей. ([Scikit-learn][1])ешь, я следующим сообщением напишу **уже не каркас, а готовый скрипт под твой кейс**:
`spaCy → кандидаты spans → uncertainty sampling → очередь на разметку → JSONL-файл для аннотации`.
