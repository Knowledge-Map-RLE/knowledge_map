## Как добавить новый термин

### Вариант 1: Через конфигурацию (предпочтительно)

Откройте `config/domain_config.json` и добавьте:

```json
{
  "compound_terms": {
    "your_new_term": {
      "parts": ["adjective", "noun"],
      "label": "adjective noun"
    }
  }
}
```

### Вариант 2: Через код (только для сложных случаев)

Добавьте метод в `CompoundTermExtractor`:

```python
def _extract_your_pattern(self, doc, debug):
    # Ваша логика
    return results
```

## Преимущества рефакторинга

1. **Читаемость**: Код разбит на логические модули
2. **Поддерживаемость**: Легко найти и исправить ошибки
3. **Расширяемость**: Новые термины через конфиг, не код
4. **Переиспользуемость**: Экстракторы можно использовать отдельно
5. **Тестируемость**: Каждый компонент можно тестировать отдельно

## Производительность

Рефакторенный код работает **так же быстро** или **быстрее** благодаря:
- Меньшему количеству условных операторов
- Лучшей локальности кода
- Оптимизированным циклам
