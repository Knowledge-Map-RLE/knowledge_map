# План реализации алгоритма преобразования онтологий в карты знаний

## Общее описание

Алгоритм преобразует 4 тестовые онтологии в карту знаний, которая представляет собой направленный ациклический граф (DAG) с блоками, содержащими 1-2 глагола в совершенном виде.

## Требования к карте знаний

1. **DAG структура**: Карта знаний должна быть направленным ациклическим графом
2. **Блоки**: Каждый блок должен содержать только один или два глагола в совершенном виде
3. **Действия**: Блок представляет собой действие (глагол в совершенном виде и связанные объекты)
4. **Связи**: Все связи в карте знаний одного типа
5. **Уникальность**: Между двумя одинаковыми блоками может быть только одна связь

## Алгоритм преобразования

### Этап 1: Извлечение глаголов и объектов

1. Идентифицируем все глаголы в онтологии
2. Определяем их лингвистические свойства
3. Фильтруем только глаголы в совершенном виде
4. Извлекаем связанные объекты

### Этап 2: Формирование блоков

1. Группируем глаголы и объекты в блоки
2. Проверяем что в каждом блоке 1-2 глагола
3. Создаем узлы графа для каждого блока

### Этап 3: Построение зависимостей

1. Анализируем семантические связи между блоками
2. Создаем направленные ребра между узлами
3. Проверяем отсутствие циклов

### Этап 4: Валидация

1. Проверяем что граф является DAG
2. Проверяем что каждый блок содержит 1-2 глагола в совершенном виде
3. Проверяем уникальность связей
