# Сводка по реализации алгоритма преобразования онтологий в карты знаний

## 1. Обзор задачи

Разработать алгоритм преобразования 4 тестовых онтологий в карту знаний, которая:
- Является направленным ациклическим графом (DAG)
- Состоит из блоков с 1-2 глаголами в совершенном виде
- Представляет зависимости действий друг от друга
