# Спецификация Карты Знаний

Цель Карты Знаний: ускорить науку, через структурирование знаний, для создания терапии старения и для продления жизни человеку.

- Микросервисная архитектура
- Есть возможность преобразовывать PDF в Markdown
- Текст Markdown должен преобразовываться в триплеты Языка Знаний
- В интерфейсе триплеты должны превращаться в обычный текст или карту знаний

## Язык Знаний

Определение на языке спецификаций (БНФ Формы Бэкуса — Наура):
```bash
Statement ::= Identifier ":" Subject "→" Predicate "→" Object
Subject ::= Concept | Statement
Object ::= Concept | Statement | Literal
```

- Утверждение образует триплет с UUID идентификатором
- Язык Знаний является вычислимым
- Если объект или субъект триплета содержит идентификатор утверждения то должна быть функция раскрывающая все зависимые утверждения, то есть вместо идентификаторов подставляется триплет на который он указывает. Триплеты считаются раскрытыми если ни в одном не осталось идентификатора
- Контекст — совокупность всех раскрытых триплетов текущего триплета
