# Спецификация Карты Знаний

Цель Карты Знаний: ускорить науку, через структурирование знаний, для создания терапии старения и для продления жизни человеку.

- Микросервисная архитектура
- Есть возможность преобразовывать PDF в Markdown
- Текст Markdown должен преобразовываться в триплеты Языка Знаний
- В интерфейсе триплеты должны превращаться в обычный текст или карту знаний
- Сервер должен считать количество заходов на сайт и количество уникальных пользователей
- Веб-приложение должно быть защищено от злоумышленников

## Каноничные данные из которых должна состоять научная статья

Эти данные должны быть предоставлены при создании новой статьи сразу в нужном для Карты Знаний формате. Должна быть возможность через классические или AI алгоритмы извлекать эти данные из cуществующих научных статей. Вне зависимости от способа это то что должно быть получено в итоге из статьи и должно проверяться валидатором при написании статьи. В интерфейсе Карты Знаний, должны быть показаны примеры каждого из пунктов при наведении на иконку вопроса. Это может помогать в планировании исследования.

- Метаданные
  - DOI
  - Название статьи
  - Авторы статьи
- Цель исследования (Формулировка научной задачи, проверка эффекта воздействия А на B)
- Поле со свободным форматом — сплошным текстом, для чего нет полей
- Универсальное поле для прямого создания триплета
- Первичная конечная точка (Primary endpoint)
- Вторичные конечные точки
- Гипотезы
  - Что пытаемся опровергнуть? Пояснение почему нужно именно опровержение — ❗
- Предпосылки — граф с онтологией, из которой исходит исследователь (Утверждения на которые он опирался. Контекст)
- Что ожидаем получить после исследования?
- На какие знания в виде утверждений опираемся?
- Дизайн исследования
  - Тип исследования
    - Case Report (Отчет по одному случаю) — описание одного пациента
    - Case Series (Отчёт по нескольким случаям) — описание нескольких похожих случаев
    - Статья A реплицирует статью B — Репликация  — независимое повторение (воспроизведение) существующего исследования
      - Противоречия или поддержание с существующими статьями
    - Original Research (Оригинальное исследование) — должны давать новые данные
    - Review (Обзор) — анализирует несколько существующих исследований в одной статье (хуже мета-анализа). Новых экспериментов нет
    - Systematic Review (Систематический обзор) — делается по протоколу, где будут искать статьи, какие статьи включат и какие исключат
    - Статья мета-анализ — проводит точный расчёт исследований по размеру эффекта среди огромного количества статей (считается самым сильным доказательством)
    - Clinical Trial (Клиническое исследование) — проводится на людях, имеет 4 фазы
      - КАКИЕ ❓
  - Рандомизация (рандомизированное контролируемое исследование, RCT)
  - Ослепление
- Материалы
- Методы
  - Методы измерения
- Эксперименты
- Критерии включения и исключения
- Биологический механизм
- На что воздействуем?
  - Клетка
  - Ткань
  - Орган
  - Биологический путь
  - Уровень вещества
- Интервенция
  - Дозировка
  - Режим дозировки
- Животная модель (T19)
  - Вид животного
    - Временная шкала событий происходящих с животными где указаны например условия содержания или предыстория модели❗
    - Связь с T55/T56 через speciesRef
- Группа животных (T55) — повторяемый блок, одна группа на экземпляр
  - groupName, speciesRef (→T19), n, conditions, purpose, interventionRef (→T18, опционально)
  - Роль (контрольная/экспериментальная) определяется тем, в какой список T14 она помещена
- Логика исследователя (Методология?)
- Сущности: даты, гены, белки, заболевания и так далее
- Определения понятий
- Предположения
- Размер выборки (n)
- Источники данных
- p-value
- Дисперсия
- Размер эффекта
- Мощность исследования
- Доверительный интервал (Confidence Interval, CI)
- Числа вместе с их названием и величинами
- Формулы с их названиями и величинами
  - Названия переменных и их величины в составе формулы
  - Каузальные графы (DAG)
  - Критерии идентифицируемости Джуда Перла

  - в стандартной форме (таблицы данных)
  - Сырые данных

- Утверждения
  - На каждое утверждение может быть противоположное с приставной "не"
  - Степень уверенности каждого утверждения (должно высчитываться Картой Знаний. Сила доказательств (Strength of Evidence). Уровень доказательности (Level of Evidence). Уверенность в доказательствах (Certainty of Evidence) — именно этот термин используется системой GRADE). Лучше хранить не число и не категорию, а список, почему именно нужно доверять утверждению (поддерживается → 18 экспериментов, опровергается → 2 экспериментами, реплицировано → 11 раз, RCT → 7, Meta-analysis → 3, Средний effect size → 0.74, Средний CI → ..., Общая выборка → 48 000, Независимых лабораторий → 14, Биологический механизм → известен). Или вектор доказательств (Статистическая поддержка = 0.96, Воспроизводимость = 0.91, Причинность = 0.84, Биологическая правдоподобность = 0.88, Согласованность исследований = 0.93 Качество дизайна = 0.79) Зависит от:
    - Размер выборки
    - p-value

    - Риск систематической ошибки
    - Метаанализ
    - Биологический механизм
    - Количество независимых лабораторий
  - A активирует B
  - A ингибирует B
  - A нокаутирует B
  - A коррелирует с B — статистическая связь между переменными
  - A причина B — казуация — причинно-следственные связи
    - Возможные смешивающие факторы (Confounders) — ❓. Например: Возраст, Пол, Питание, Курение
  - A противоречит B
  - A доказывает B

## Язык Знаний

Определение на языке спецификаций (БНФ Формы Бэкуса — Наура):
```bash
Statement ::= Identifier ":" Subject "→" Predicate "→" Object
Subject ::= Concept | Statement
Object ::= Concept | Statement | Literal
```

- Утверждение образует триплет с UUID идентификатором
- Язык Знаний является вычислимым
- Если объект или субъект триплета содержит идентификатор утверждения то должна быть функция раскрывающая все зависимые утверждения, то есть вместо идентификаторов подставляется триплет на который он указывает. Триплеты считаются раскрытыми если ни в одном не осталось идентификатора который может раскрыться
- Контекст — совокупность всех раскрытых триплетов текущего триплета

## Паттерны успешные и не успешные

- Успешным паттерном являются тот набор (граф) утверждений который приводит к положительному результату исследования или иначе, гипотеза подтвердилась (не опровергнута).
- Не успешным паттерном является тот набор (граф) утверждений который приводит к отрицательному (неправильному) результату исследования или иначе, гипотеза не подтвердилась или если исследование содержит ошибки в методах или дизайне исследования.
